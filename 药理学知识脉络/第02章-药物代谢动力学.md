## ADME 定义

**原理**：药动学（pharmacokinetics）研究机体对药物的处置（disposition）——药物在体内的动态变化规律，即 **A**bsorption（吸收）→ **D**istribution（分布）→ **M**etabolism（代谢）→ **E**xcretion（排泄）四大过程，缩写 ADME。

**影响因素**：给药途径、剂型、个体差异、肝肾功能等——每一个环节都会改变血药浓度随时间的变化曲线。

**反向思考**：ADME 四个环节是"串联"的——吸收不好，后面全白搭；代谢快排泄快，药效就短。临床调药就是在调这四个环节。

**实际例子**：同一药物（如地高辛）口服 vs 静注，起效速度和强度完全不同——因为绕过了吸收环节。

## 第一节 运输方式（跨膜转运）

**原理**：药物要完成 ADME，第一步是穿越生物膜。**生物膜基本结构为脂质双分子层**——中间是疏水的脂肪酸链，两侧是亲水的磷酸基团，所以**脂溶性药物容易透过**，水溶性大分子需要特殊通道。

**影响因素**：药物脂溶性、分子大小、解离状态（pKa vs 环境 pH）、膜两侧浓度差、转运蛋白、能量供给。

**反向思考**：膜是"亲油的门"——所有药物过膜问题，本质都是"我够不够油？解离了没有？有没有人帮我搬？"

**实际例子**：吸入麻醉药（七氟烷）脂溶性极高，快速透过血脑屏障起效；而神经肌肉阻滞药（筒箭毒碱类）是水溶性大分子，过不了膜只能留在血液中。

### 分类：

#### 1. 被动转运（顺浓度梯度，不耗能）

##### （1）简单扩散（脂溶扩散）

**原理**：药物**从高浓度侧向低浓度侧**顺浓度梯度穿过脂质双分子层，不消耗能量、不需要载体，转运速率取决于**脂溶性和解离度**。只有**非解离型（分子型）**才容易透过膜。

**影响因素**：① 药物的 pKa 与膜两侧 pH（决定解离比例）；② 脂溶性；③ 浓度梯度；④ 膜面积与血流量。规律：**弱酸性药物在酸性环境中非解离型多，容易透过生物膜；弱碱性药物反之（碱性药物类比）**——酸酸碱碱促吸收。

**反向思考**：
- 如果弱酸性药物到了碱性环境（如小肠 pH 偏高）→ 解离型增多 → 吸收减少？→ 不一定！小肠表面积大+血流量大，实际吸收面积优势常抵消 pH 劣势。
- 中毒解救的逆向利用：苯巴比妥（弱酸）中毒 → **碳酸氢钠碱化尿液** → 尿中非解离型减少、解离型增多 → 肾小管重吸收减少 → 排泄加快。
- 反之，若误服过量碱性药物（如阿托品类），可酸化尿液加速排泄。

**实际例子**：
- **苯巴比妥中毒 → 碳酸氢钠洗胃/碱化尿液**（你的大纲原例）
- 阿司匹林（弱酸 pKa≈3.5）在胃中（pH 1-2）几乎不解离，可被胃黏膜吸收——这就是"空腹胃痛"的原因之一
- 弱碱性药物吗啡在胃中解离多吸收少，主要在小肠吸收

##### （2）易化扩散

**原理**：借助**载体蛋白**（转运体），**顺浓度梯度**转运，不耗能（能量来自浓度梯度本身），有**饱和现象**和**竞争性抑制**，比简单扩散快。

**影响因素**：载体数量（饱和）、底物浓度、竞争底物。

**反向思考**：载体是"公交车"——车有限（饱和），同路的人多就抢座（竞争抑制）。药物过量时转运速度不会无限增加。

**实际例子**：葡萄糖进入红细胞靠 GLUT1 易化扩散；氨基酸跨膜。

#### 2. 主动转运（逆浓度梯度，耗能）

##### （1）原发性主动转运

**原理**：**直接利用 ATP 分解产生的能量**，逆浓度梯度/逆电化学梯度转运，需载体、有饱和与竞争抑制、可被阻断。

**影响因素**：ATP 供给、载体表达量（上调/下调）、抑制剂。

**反向思考**：这是细胞的"搬运工"——一旦 ATP 耗竭（缺氧、中毒），主动转运全线瘫痪，药物分布排泄都会乱。

**实际例子**：Na⁺-K⁺-ATPase（钠泵）；肾小管上皮 P-糖蛋白（P-gp）外排药物进入尿液。

##### （2）继发性主动转运

**原理**：**与转运离子（如 Na⁺）结合**，利用离子顺浓度梯度下降释放的能量"搭便车"，逆浓度转运另一物质，本身不直接耗 ATP。

**影响因素**：离子梯度大小、转运体类型（同向/反向转运体）、底物竞争。

**反向思考**：离子梯度是"蓄电池"，任何破坏 Na⁺ 梯度的因素（哇巴因抑制钠泵）都会连累继发性转运。

**实际例子**：**SGLT2（钠-葡萄糖共转运体）**——降糖药达格列净抑制 SGLT2，让葡萄糖从尿中排出；肾小管有机阴离子/阳离子转运体（OAT/OCT）分泌青霉素、尿酸。

#### 3. 膜动转运（胞饮 / 胞吐）

**原理**：细胞膜内陷（**胞饮**）或囊泡与膜融合释放（**胞吐**），用于**大分子**、蛋白质、病毒颗粒等转运，耗能。

**影响因素**：物质分子大小、细胞吞噬能力、能量。

**反向思考**：小分子药物几乎不走这条路；只有大分子药物（蛋白药、脂质体、纳米制剂）依赖它——这也是多数蛋白药只能注射的原因之一。

**实际例子**：口服疫苗（如脊灰减毒活疫苗）经肠道 M 细胞胞饮摄取；脂质体阿霉素靠胞吞进入肿瘤细胞。

## 药物转运体 P-gp

**原理**：P-糖蛋白（P-gp，由 MDR1 基因编码）是一种**外排泵**（原发性主动转运），把药物**从细胞内泵回管腔/血液**，广泛存在于**肠上皮、血脑屏障内皮、肾小管、肝细胞胆小管侧**——它是身体的"守门员"，限制药物进入，促进药物排出。

**影响因素**：① 诱导剂（利福平、苯妥英钠→P-gp 表达↑）；② 抑制剂（奎尼丁、维拉帕米、葡萄柚汁→P-gp 功能↓）；③ 基因多态性（MDR1 C3435T，个体外排能力差异）；④ 疾病状态。

**反向思考**：
- P-gp 被抑制 → 药物吸收↑、脑内浓度↑ → 药效增强但**中毒风险骤增**（地高辛+奎尼丁经典致死组合）。
- P-gp 被诱导 → 药物被快速排出 → 药效显著下降（利福平+地高辛）。
- 反过来利用：P-gp 抑制剂联合化疗药，提高肿瘤细胞内药物浓度（逆转多药耐药 MDR）。

**实际例子**：**地高辛 + 奎尼丁**：奎尼丁抑制 P-gp → 地高辛血药浓度翻倍 → 心动过缓/中毒（临床必考经典）；洛哌丁胺（止泻药）被 P-gp 泵出脑外所以中枢副作用小——若合用 P-gp 抑制剂则可能出现中枢抑制。

## 吸收（Absorption）

**原理**：药物从给药部位进入血液循环的过程。口服药物经胃肠道吸收后**先经门静脉入肝**，部分药物被肝代谢灭活——即**首关消除（首过效应）**，使进入体循环的药量减少。

**影响因素**（你的大纲）：**理化性质、剂型、给药途径、机体因素（胃肠内 pH、胃排空速度、肠蠕动、胃肠血流、食物、肠道菌群）**；此外还有首关消除强度、转运体（P-gp）。

**反向思考**：
- 首关消除强的药口服等于白吃？→ 换给药途径（舌下、经皮、注射）或加大剂量或做成前药。
- 吸收太快一定是好事？→ 起效快但血药浓度峰高，毒性风险大（缓释制剂的本质就是"削峰填谷"）。
- 胃排空慢（饱食、抗胆碱药）→ 弱酸药在胃停留久吸收增加；胃排空快 → 药物快速入肠。

**实际例子**：
- **硝酸甘油首关消除极强 → 舌下含服**（不经过门静脉）→ 1-2 分钟起效
- **胰岛素是蛋白质 → 口服被消化破坏 → 必须注射**
- 青霉素 G 耐酸差 → 改青霉素 V 或注射给药
- 缓释/控释制剂（硝苯地平控释片）——减少给药次数、平稳血药浓度

## 分布（Distribution）

**原理**：药物从血液向各组织器官的转运过程。**血浆中药物浓度可间接反映靶器官的药物浓度**（你的大纲原句）——但前提是分布达到平衡，且靶器官不是特殊屏障区。

**影响因素**（你的大纲）：**理化性质、器官血流量和膜的通透性、血浆蛋白结合率、组织亲和性、生理屏障（血脑屏障、胎盘屏障、血眼屏障）、转运体**。

**反向思考**：
- 血浆蛋白结合率高 ≠ 药效强：结合型是"仓库"，**只有游离型**才有药理活性；结合率 99% 的药，游离型从 1% 变 2%，药效翻倍 → **置换反应可致命**。
- 血脑屏障是"双刃剑"：挡住毒物，也挡住药物——脑膜炎时屏障通透性↑，青霉素才能进入（治疗剂量）。
- 组织亲和性大的药（Vd 大）血药浓度低但组织浓度高，透析/换血都难以清除。

**实际例子**：
- **华法林（结合率 99%）+ 保泰松/阿司匹林** → 游离型骤增 → 出血（经典置换反应）
- 脑膜炎时大剂量青霉素透过血脑屏障（炎症使屏障通透性增加）
- 氯喹大量沉积于组织（Vd 极大），血药浓度低却组织蓄积——停药后仍可复发
- 脂溶性药（硫喷妥钠）迅速入脑起效，又迅速再分布到脂肪——麻醉苏醒快

## 代谢（Metabolism）

**原理**：药物在体内发生化学结构转化的过程，**以肝脏为主**（你的大纲）。分两类反应：
- **Ⅰ相反应**：氧化、还原、水解（引入极性基团）
- **Ⅱ相反应**：结合反应（与葡萄糖醛酸、硫酸、乙酰基等结合，极性大增利于排泄）
代谢酶分**专一性酶**（如 MAO、AChE）与**非专一性酶**（如 **CYP450 肝药酶系**，代谢绝大多数药物）。

**影响因素**（你的大纲）：**生理因素（种属、种族、年龄、性别）**、**病理因素（肝病、遗传缺陷）**、**环境因素（酶诱导剂与酶抑制剂）**。

**反向思考**：
- **酶诱导**（CYP450 表达↑）→ 自身及其他药代谢加快 → 药效↓：利福平+口服避孕药 → 避孕失败；苯妥英钠长期用反而需要加量（自身诱导）。
- **酶抑制**（CYP450 被占/被抑）→ 药物蓄积 → 中毒：酮康唑/伊曲康唑/红霉素抑制 CYP3A4 + 特非那定（原药）→ QT 延长、尖端扭转型室速（曾致死的经典案例）。
- **前药**需经代谢活化：可待因→吗啡（CYP2D6），**CYP2D6 慢代谢者吃可待因无效**；氯吡格雷→活性代谢物，CYP2C19 慢代谢者抗血小板差。
- 遗传多态性 = 天生"快/慢代谢者"，同剂量血药浓度可差 10 倍以上。

**实际例子**：
- **西咪替丁抑制 CYP450 → 华法林/茶碱代谢减慢 → 中毒**（临床常需减量）
- **葡萄柚汁抑制肠壁 CYP3A4 → 非洛地平/辛伐他汀血药浓度升高**
- 对乙酰氨基酚过量 → 饱和结合途径 → 转走 CYP2E1 氧化 → 生成毒性代谢物 NAPQI → 肝坏死（**乙酰半胱氨酸解救**）
- 老年人肝血流量↓、肝药酶↓ → 代谢减慢，剂量应酌减

## 排泄（Excretion）

**原理**：药物原形或代谢物排出体外的过程。主要途径：
- **肾排泄**：肾小球滤过 + 肾小管主动分泌 + 肾小管重吸收 三环节共同决定；衡量指标为**肾清除率**
- **胆汁排泄**：药物经胆汁排入肠道——部分可被肠道重新吸收（**肝肠循环**），指标为胆汁排泄率
- **其他**：肺（挥发性药）、汗液、唾液、乳汁（哺乳用药风险）

**影响因素**：尿 pH（解离度）、肾功能（GFR）、肾血流、转运体（OAT/OCT、P-gp）、胆汁流量与肠道菌群（肝肠循环）、蛋白结合（只有游离型可滤过）。

**反向思考**：
- **碱化尿液 → 弱酸药排泄↑**（苯巴比妥中毒解救）；**酸化尿液 → 弱碱药排泄↑**（阿托品类、苯丙胺中毒）——"酸酸碱碱促吸收，碱酸碱酸促排泄"。
- 肾小管分泌是主动过程，可被**竞争性抑制**——丙磺舒抢青霉素的分泌通道 → 青霉素血药浓度↑（早期"省钱疗法"，现用于促尿酸排泄治痛风）。
- 肝肠循环 → 药物反复入血 → t½ 延长 → 停药后血药浓度下降慢（如洋地黄毒苷）；考来烯胺在肠道吸附药物打断肝肠循环可加速清除。
- 肾功能不全 → 经肾排泄药物蓄积 → 中毒（氨基糖苷类肾毒性+耳毒性）。

**实际例子**：
- 苯巴比妥中毒：**碳酸氢钠碱化尿液** + 利尿（你的大纲原例）
- **地高辛 60% 以上经肾排泄** → 肾衰患者易中毒，按肌酐清除率减量
- 丙磺舒+青霉素：竞争肾小管分泌，延长青霉素作用时间
- 吸入麻醉药（七氟烷）主要经肺原形呼出——停药即苏醒
- 哺乳期慎用脂溶性药（乳汁排泄，婴儿暴露）

## 基本理论

### 速率过程：一级、零级、米-曼速率

**原理**：
- **一级动力学**：单位时间消除**恒定比例**（如每小时 10%），t½ 恒定，绝大多数药物在治疗剂量下属此类；**经过 5 个 t½ 基本达稳态，停药 5 个 t½ 基本清除**。
- **零级动力学**：单位时间消除**恒定数量**，与浓度无关（载体/酶**饱和**），t½ 随剂量增大而延长——剂量微增，血药浓度剧增。
- **米-曼速率（Michaelis-Menten）**：介于两者之间——低浓度时近似一级，高浓度（酶饱和）时趋近零级，用 Vmax、Km 描述。

**影响因素**：剂量大小、酶/转运体饱和点（Km）、个体代谢能力、合并用药。

**反向思考**：
- 零级动力学的药"多一粒"可能"多一条命"——剂量调整必须小步走、勤监测。
- 一级动力学药物给药间隔 = t½ 是合理的起点；间隔过长血药浓度波动大，过短易蓄积。

**实际例子**：
- **乙醇**：体内按零级代谢（酗酒者每小时清除量固定，所以"醒酒"需要固定时间）
- **苯妥英钠**：治疗浓度附近即达饱和 → 剂量从 300mg 加到 400mg，血药浓度可翻倍 → 中毒（经典非线性）
- 阿司匹林大剂量（抗炎）时部分按零级消除

### 模型：房室模型、生理学模型、药动学-药效学结合模型

**原理**：
- **房室模型**：把机体抽象为若干"房室"。**一室模型**（药物瞬间均匀分布全身）；**二室模型**（先快速分布到中央室[血浆、血流丰富组织]，再缓慢分布/消除于周边室[脂肪、深部组织]）；**非房室模型**（矩量法，直接用 AUC 计算参数，无需假设）。
- **生理学模型**：按真实器官血流量、组织容积建模，更真实但复杂。
- **药动学-药效学结合模型（PK-PD）**：把"浓度-时间"与"浓度-效应"联系起来，指导给药方案设计。

**影响因素**：药物的组织亲和力、血流灌注、模型选择（数据拟合优度）。

**反向思考**：二室模型的药（如地高辛）"血药浓度降得快"≠"药没了"——可能只是分布进了组织；采血时机错了会误判 t½。

**实际例子**：
- 硫喷妥钠：经典二室——先快速入脑（起效），再向脂肪再分布（苏醒）
- **地高辛**：二室模型，组织结合多，Vd 大，t½ 长（36h+），需负荷剂量
- 抗菌药 PK-PD：β-内酰胺类**时间依赖性**（%T>MIC 达标）、氨基糖苷类**浓度依赖性**（Cmax/MIC）——决定一天一次还是多次给药

### 药动学参数：t½、Vd、AUC、F、CL、稳态等

**原理**：
- **半衰期（t½）**：血药浓度下降一半所需时间。决定给药间隔与达稳/清除时间。
- **表观分布容积（Vd）**：理论上药物均匀分布所需的体液容积 = 体内药量/血药浓度。反映分布倾向，**不一定是真实容积**。
- **血药浓度-时间曲线下面积（AUC）**：反映药物**总暴露量**（吸收总量 × 消除速度的净结果）。
- **生物利用度（F）**：药物进入体循环的程度和速度 = AUC 口服/AUC 静注（**绝对**）；或与参比制剂比（**相对**）。受首关消除影响。
- **清除率（CL）**：单位时间清除药物的血浆容积（= 肾清除率 + 肝清除率 + 其他），是最重要的整体清除指标。
- **稳态浓度（Css）**：按固定间隔恒量给药，经 **5 个 t½** 后血药浓度达到的坪值；给药间隔= t½ 时波动最小。

**影响因素**：个体肝肾功能（CL 主导）、给药方案、制剂工艺（F）、蛋白结合（Vd 计算需用游离浓度）、合并用药。

**反向思考**：
- Vd 大的药（氯喹 Vd≈数百升）血药浓度"看起来低"，但组织里满满的——测血药浓度监测（TDM）时要注意取样时机与游离浓度。
- 想**快速达稳**怎么办？给**负荷剂量**（≈ 维持量 × 累积因子），但要防首剂过高中毒。
- CL 只能反映"清除药物的血浆容积"，不能直接换算排泄量——先算 CL 再定维持量 = 维持量 = CL × Css。
- F 低的药改口服不行就改途径（前面硝酸甘油的例子再次适用）。

**实际例子**：
- **地高辛**：t½≈36h，需**负荷剂量**（0.5mg×2-3 次）快速达稳，之后小剂量维持；肾衰者 CL↓ → 减量
- **庆大霉素**：主要经肾排泄，按肌酐清除率调整给药间隔；浓度依赖性杀菌 → 一天一次给药
- 同一厂家不同批号/仿制药生物利用度差异 → 强调制剂等效性（BE）
- 苯妥英钠 TDM：治疗窗 10-20 μg/ml，零级动力学 → 必须监测血药浓度调整剂量

## 反向思考·临床思维自测（本章核心）

1. 苯巴比妥（弱酸）中毒为什么要碱化尿液？（→ 增加解离型，减少重吸收）
2. 硝酸甘油为什么舌下含服而不是吞服？（→ 避开首关消除）
3. 地高辛和奎尼丁合用为什么会中毒？（→ 奎尼丁抑制 P-gp，地高辛浓度翻倍）
4. 华法林和保泰松合用为何出血？（→ 蛋白置换，游离型华法林骤增）
5. 利福平为什么让口服避孕药失效？（→ 酶诱导，CYP450 代谢加快）
6. 可待因对什么人无效？（→ CYP2D6 慢代谢者，无法活化成吗啡）
7. 为什么说苯妥英钠剂量调整要"如履薄冰"？（→ 零级/米-曼动力学，剂量微增浓度剧增）
8. 肾功能不全患者用庆大霉素要注意什么？（→ CL 下降蓄积，按肌酐清除率延长间隔）

> 记忆口诀：**酸酸碱碱促吸收，碱酸碱酸促排泄；五个半衰期达稳态，五个半衰期基本清。**
