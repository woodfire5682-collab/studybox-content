## 本章总览：化学合成抗菌药的两大支柱

**原理**：人工合成抗菌药（synthetic antibacterial agents）指**非抗生素来源**、通过化学合成方法获得的抗菌药。与天然/半合成抗生素（β-内酰胺类、氨基糖苷类等）不同，它们的母核是**全合成**的。本章重点是两大支柱：
- **喹诺酮类（quinolones）**：以**诺氟沙星（norfloxacin）**，特别是**环丙沙星（ciprofloxacin）**为代表，属**广谱、浓度依赖性**杀菌药，通过抑制细菌**DNA 回旋酶/拓扑异构酶 Ⅳ** 发挥作用。
- **磺胺类（sulfonamides）**：以**磺胺甲噁唑（sulfamethoxazole，SMZ）**和**磺胺嘧啶（sulfadiazine，SD）**为代表，属**抑菌药**，通过**竞争性抑制二氢叶酸合成酶**、阻断叶酸合成发挥作用。常与**甲氧苄啶（trimethoprim，TMP）**联用（复方磺胺甲噁唑 SMZ-TMP，即复方新诺明）产生**协同**。

**影响因素**：药物抗菌谱与作用机制、细菌耐药机制、给药途径（喹诺酮口服吸收好、可静脉）、组织分布（喹诺酮在泌尿生殖道浓度高）、肾功能（多数喹诺酮/磺胺经肾排泄，需按肾功能减量）、年龄（喹诺酮禁用于儿童/孕妇，磺胺禁用于新生儿）、是否联用（磺胺+TMP 协同）。

**反向思考**：喹诺酮是"抑菌照杀、广谱高效"，但**对儿童骨骺软骨有损伤（禁用于 18 岁以下）**、可致**QT 间期延长与肌腱断裂**；磺胺是"抑菌药，只抑不杀"，且**易致过敏（皮疹、Stevens-Johnson 综合征）与结晶尿**。两者都是"便宜好用但各有雷区"的经典抗菌药。

**实际例子**：**诺氟沙星、环丙沙星**治疗泌尿系感染；**左氧氟沙星（levofloxacin）**治疗呼吸道感染；**复方磺胺甲噁唑**治疗肺孢子菌肺炎、尿路感染；**磺胺嘧啶**治疗流行性脑脊髓膜炎。

## 第一节 喹诺酮类药物

### 一、喹诺酮类药物概述

**原理**：喹诺酮类（quinolones）作用机制是**抑制细菌 DNA 回旋酶（DNA gyrase，即拓扑异构酶 Ⅱ）和拓扑异构酶 Ⅳ**，这两种酶负责 DNA 超螺旋的引入/解开与染色体分裂，抑制后细菌 DNA 复制与修复受阻 → **快速杀菌**。属**浓度依赖性**抗菌药，抗菌效果与**血药峰浓度/最低抑菌浓度（Cmax/MIC）**相关。按化学结构和抗菌谱演变分为**四代**（详见下表）。

**影响因素**：药物代数（抗菌谱宽窄、对铜绿假单胞菌/厌氧菌活性）、给药浓度与剂量、细菌耐药机制（靶酶基因突变、外排泵、质粒介导）、合并用药（与含 Mg²⁺/Al³⁺ 的抗酸药合用吸收减少）、肾功能、年龄/孕产、光敏性。

**反向思考**：
- 喹诺酮是**浓度依赖性**杀菌药，与其"一天多次小剂量"不如"一天一次足量"——**峰浓度越高杀菌越强、越不易耐药**；但**浓度过高又增加中枢与 QT 毒性**。
- 喹诺酮**抑制肝药酶（CYP1A2 等）**，与**茶碱、华法林**合用可致后者血药浓度升高 → **茶碱中毒、出血**（临床常需减量）。
- **含 Mg²⁺/Al³⁺ 抗酸药、钙剂、铁剂**会与喹诺酮形成**螯合物** → 吸收显著下降，需**间隔 2 小时以上**给药。
- **18 岁以下禁用**：喹诺酮损伤幼龄动物的**软骨发育**（致关节病），孕妇、哺乳期慎用。
- 喹诺酮可致**QT 间期延长**（尖端扭转型室速），与**胺碘酮、红霉素**等延长 QT 药合用风险叠加。
- 多数喹诺酮**经肾排泄**，肾功能不全需减量；但**莫西沙星主要经肝代谢**，肝功能不全者注意。

**实际例子**：**环丙沙星 + 茶碱** → 茶碱浓度升高中毒；**诺氟沙星与含铝抗酸药同服** → 疗效下降；**左氧氟沙星**治疗社区获得性肺炎；**莫西沙星（moxifloxacin）**用于呼吸道感染但对铜绿假单胞菌无效。

### 二、喹诺酮类药物分代对比

| 代 | 代表药（英文） | 抗菌谱特点 | 临床应用 | 主要不足 |
|---|---|---|---|---|
| 第一代 | 萘啶酸（nalidixic acid） | 主要抗**革兰阴性杆菌**，窄谱 | 尿路感染（现已少用） | 抗菌谱窄、易耐药 |
| 第二代 | 吡哌酸（pipemidic acid）、诺氟沙星（norfloxacin） | 抗革兰阴性杆菌增强，对铜绿假单胞菌有一定作用 | 泌尿系、肠道感染 | 对革兰阳性菌弱 |
| 第三代 | 环丙沙星（ciprofloxacin）、左氧氟沙星、氧氟沙星（ofloxacin）、洛美沙星 | 广谱，抗革兰阴性杆菌强（含铜绿假单胞菌）、对肺炎支原体等有效 | 呼吸道、泌尿、胃肠道、骨与关节感染 | 对厌氧菌弱 |
| 第四代 | 莫西沙星、吉米沙星（gemifloxacin）、加替沙星 | 广谱，显著增强对**革兰阳性菌、厌氧菌、肺炎链球菌**活性 | 呼吸道感染、腹腔感染、皮肤软组织感染 | 中心神经系统/肝毒性、QT 延长 |

### 三、常用喹诺酮类药物

**原理**：按不同代别/部位选用：
- **诺氟沙星（norfloxacin）**：第二代，口服吸收较好，**尿药浓度高**，用于敏感菌所致**泌尿生殖系统感染、肠道感染**。
- **环丙沙星（ciprofloxacin）**：第三代，对**铜绿假单胞菌**作用强，是抗绿脓感染的重要选择，用于复杂尿路感染、呼吸道、肠道、骨髓炎。
- **左氧氟沙星（levofloxacin）**：第三代，**抗菌谱广、组织穿透好**，对呼吸道病原体（肺炎链球菌、支原体、衣原体）效果好，用于呼吸道、泌尿道感染；**口服生物利用度高（近 100%）**，可口服/静滴序贯。
- **莫西沙星（moxifloxacin）**：第四代，**对革兰阳性菌、厌氧菌、肺炎链球菌强**，用于呼吸道感染（CAP、慢性支气管炎急性加重）；**但抗铜绿假单胞菌弱、QT 延长及肝毒性相对突出**。

**影响因素**：感染部位与病原体、是否需要覆盖铜绿/厌氧菌、患者年龄（<18 岁禁用）、肾功能（多数经肾排泄减量）、肾功能不全者血透后追加、是否有 QT 延长风险、是否合用含金属阳离子药物、光敏性（需避光）。

**反向思考**：
- **环丙沙星**虽抗铜绿强，但**对肺炎链球菌/厌氧菌弱**——治社区获得性肺炎不能只靠环丙沙星；**莫西沙星**抗厌氧、抗阳性强，但**管不了铜绿**。"没有包打天下的喹诺酮"。
- **左氧氟沙星**口服生物利用度近乎 100%，可**序贯治疗**（静滴三天后改口服），减少住院。
- **喹诺酮耐药**日益严重（尤其大肠埃希菌对环丙沙星耐药率高），**不可作为经验性一线滥用**，用药前尽量送检+药敏。

**实际例子**：**左氧氟沙星**用于社区获得性肺炎；**环丙沙星**用于铜绿假单胞菌尿路感染；**诺氟沙星**用于单纯膀胱炎；**莫西沙星**用于慢性支气管炎急性加重。

## 第二节 磺胺类药物

### 一、磺胺类药物概述

**原理**：磺胺类（sulfonamides）与**对氨基苯甲酸（PABA）**结构类似，**竞争性抑制细菌的二氢叶酸合成酶（dihydropteroate synthase，DHPS）**，阻断叶酸合成。因**哺乳动物细胞可直接利用外源性叶酸**、不依赖自身合成，故磺胺类**选择性地抑制细菌**而对人体毒性相对小。属**抑菌药**（fastidious 为抑菌而非杀菌），需达到**足够血药浓度并持续**，且**要求机体免疫配合**清除细菌。常与甲氧苄啶（TMP）合用，**双重阻断叶酸代谢**产生协同杀菌。

**影响因素**：细菌是否依赖自身合成叶酸、给药剂量与频次（需维持有效浓度）、组织分布（磺胺易透过血脑屏障、进入脑脊液与泌尿系统）、pH 与溶解度（酸性尿易析晶）、是否联用 TMP、患者肝肾功能、过敏史（磺胺过敏交叉）。

**反向思考**：
- 磺胺类是**抑菌药**，**只抑不杀**——"浓度要够、时间要足"；否则不仅无效，还易**诱导耐药**。这与杀菌药（β-内酰胺、喹诺酮）形成鲜明对比。
- **磺胺 + TMP（复方磺胺甲噁唑）**：分别抑制**二氢叶酸合成酶**和**二氢叶酸还原酶**（TMP 抑制 DHFR）——**双重阻断叶酸通路**，把"抑菌"升级为"协同杀菌"，并**降低耐药**。这是本章最经典的联用。
- **结晶尿**：磺胺及乙酰化物在**酸性/浓缩尿**中溶解度低 → 析晶损伤肾小管 → 需**大量饮水、碱化尿液**（伴碳酸氢钠），这也是"磺胺要喝水利尿"的原因。
- **过敏反应**：磺胺易致皮疹、**Stevens-Johnson 综合征/中毒性表皮坏死松解症**；对磺胺过敏者**交叉过敏**（含磺胺基团药物）。
- **新生儿/孕妇禁用**：磺胺竞争性置换胆红素与血浆蛋白、抑制葡萄糖-6-磷酸脱氢酶（G6PD）→ **高胆红素血症/核黄疸、溶血性贫血**。
- 磺胺可增强**华法林、磺脲类降糖药**的效应（置换血浆蛋白、抑制代谢）→ 出血/低血糖风险。

**实际例子**：**复方磺胺甲噁唑（SMZ-TMP，复方新诺明）** 治疗尿路感染、**肺孢子菌肺炎（PCP）**、伤寒、痢疾；**磺胺嘧啶（sulfadiazine）**用于**流行性脑脊髓膜炎**（易透过血脑屏障）；**磺胺米隆、磺胺嘧啶银**外用抗感染（烧伤创面）。

### 二、常用磺胺类药物

**原理**：按临床应用与溶解/吸收特点分为：
- **全身性磺胺（口服吸收好）**：**磺胺甲噁唑（sulfamethoxazole，SMZ）** 作用较强、常与 TMP 组成复方；**磺胺嘧啶（sulfadiazine，SD）** 易透过血脑屏障，用于流脑；
- **肠道难吸收磺胺**：**柳氮磺吡啶（sulfasalazine）** 肠道分解为磺胺吡啶+5-氨基水杨酸，用于**溃疡性结肠炎、类风湿关节炎**；
- **外用磺胺**：**磺胺嘧啶银（silver sulfadiazine）、磺胺米隆（mafenide，甲磺灭脓）** 用于烧伤/创面感染，抗菌谱广。

**影响因素**：感染部位（需不需透血脑屏障/入肠）、是否需局部用、肾功能（多数经肾排泄，肾功能不全避免用长效磺胺/减量）、肝功能（磺胺经肝乙酰化代谢）、是否合并体液丢失、过敏史、G6PD 缺乏人群（诱发溶血）。

**反向思考**：
- **磺胺嘧啶**能透血脑屏障是**优点**（治流脑），但也提示它**易在中枢产生作用**；在肾功能/尿量不足时要防**结晶尿**。
- **柳氮磺吡啶**虽是"磺胺"，但它的治疗靶点是**肠道炎症/关节炎**，靠**局部释放 5-氨基水杨酸（美沙拉嗪）**起作用——"磺胺骨架 + 靶向释放"是改构思路。
- **复方新诺明**疗效好，但**对 G6PD 缺乏者（蚕豆病）诱发溶血、对磺胺过敏者交叉过敏、抑制骨髓**——用药前问过敏史、慎用于老年人/孕妇。

**实际例子**：**复方磺胺甲噁唑**治疗肺孢子菌肺炎（大剂量疗程）；**柳氮磺吡啶**治疗溃疡性结肠炎、类风湿关节炎；**磺胺嘧啶银**外用于烧伤创面；**磺胺嘧啶**用于流脑。

## 第三节 其他合成抗菌药（简述）

**原理**：除喹诺酮、磺胺类外，人工合成抗菌药还包括**硝基呋喃类**与**硝基咪唑类**：
- **硝基呋喃类**：**呋喃妥因（nitrofurantoin）**——在**尿中浓度高**、专门治疗**下尿路感染**；**呋喃唑酮（furazolidone，痢特灵）**——治肠道感染。机制为抑制细菌多种酶、干扰代谢。
- **硝基咪唑类**：**甲硝唑（metronidazole）**——在**厌氧菌/原虫**细胞内被还原为活性代谢物、破坏 DNA，是**抗厌氧菌**与**抗滴虫/阿米巴**的首选；**替硝唑（tinidazole）** 作用类似、疗程短。

**影响因素**：感染部位（尿路/肠道/厌氧环境）、是否需抗原虫、肝功能、饮酒（甲硝唑+酒精致双硫仑样反应）、妊娠。

**反向思考**：**呋喃妥因**只在尿中有效、对组织感染无效，故仅用于**下尿路感染**；**甲硝唑**是"厌氧杀手"，但**对需氧菌无效**——"治厌氧菌必须想到甲硝唑"。甲硝唑**抑制乙醛脱氢酶**，与酒精同用产生**双硫仑样反应**（面色潮红、恶心、心悸）。

**实际例子**：**呋喃妥因**治疗膀胱炎；**甲硝唑**治疗滴虫性阴道炎、阿米巴、细菌性阴道病、腹腔/盆腔厌氧菌感染、幽门螺杆菌根除之一等；**替硝唑**用于滴虫病。

## 易混淆对比速查

| 对比项 | 喹诺酮类 | 磺胺类 |
|---|---|---|
| 作用机制 | 抑制 DNA 回旋酶/拓扑异构酶 Ⅳ | 竞争性抑制二氢叶酸合成酶（DHPS） |
| 药效类型 | **杀菌药**（浓度依赖性） | **抑菌药**（需持续有效浓度） |
| 代表药 | 环丙沙星、左氧氟沙星、莫西沙星 | 磺胺甲噁唑、磺胺嘧啶、柳氮磺吡啶 |
| 主要禁忌 | <18 岁、孕妇（软骨损伤）、QT 延长 | 新生儿、孕妇（核黄疸）、G6PD 缺乏、磺胺过敏 |
| 典型不良反应 | 关节软骨损伤、QT 延长、肌腱炎/断裂、光敏 | 结晶尿、过敏（SJS）、骨髓抑制、溶血 |
| 联用协同 | 与甲硝唑/他药联用（无固定"经典组合"） | **与 TMP 联用（复方新诺明）协同杀菌** |
| 排泄 | 多经肾排泄（莫西沙星经肝） | 多经肾排泄（需碱化尿液防结晶） |

| 对比项 | 磺胺 | 甲氧苄啶（TMP） |
|---|---|---|
| 靶酶 | 二氢叶酸合成酶（DHPS） | 二氢叶酸还原酶（DHFR） |
| 作用环节 | 阻断叶酸合成上游 | 阻断叶酸合成下游 |
| 单用 | 抑菌 | 抑菌 |
| 联用 | **协同杀菌、降低耐药** | 同上 |

## 反向思考·自测题（答案要点）

1. 为什么喹诺酮类属于"浓度依赖性"抗菌药？（→ 抗菌效果与 Cmax/MIC 相关，峰浓度越高杀菌越强；宜一天一次足量给药，避免小剂量多次）
2. 为什么喹诺酮类与含 Mg²⁺/Al³⁺ 抗酸药同服疗效下降？（→ 形成螯合物、吸收减少；需间隔 2 小时以上）
3. 为什么喹诺酮类禁用于儿童？（→ 损伤幼龄动物软骨发育、致关节病；18 岁以下禁用，孕妇哺乳期慎用）
4. 磺胺类药物为什么必须"饮水利尿"并碱化尿液？（→ 磺胺及乙酰化物在酸性浓缩尿中溶解度低、易析晶致肾损伤；大量饮水+碳酸氢钠碱化尿防结晶尿）
5. 为什么磺胺与甲氧苄啶联用能"协同杀菌"？（→ 分别抑制二氢叶酸合成酶（DHPS）与二氢叶酸还原酶（DHFR），双重阻断叶酸代谢通路，抑菌升级为杀菌、降低耐药）
6. 磺胺类为什么是"抑菌药"而非"杀菌药"？（→ 仅竞争性抑制 DHPS、阻断叶酸，不直接杀灭细菌；需机体免疫配合，浓度要够、时间要足）
7. 甲硝唑的作用机制与临床定位是什么？与酒精合用有何风险？（→ 在厌氧菌/原虫细胞内被还原为活性物破坏 DNA；抗厌氧菌、抗滴虫/阿米巴；抑制乙醛脱氢酶，与酒精产生双硫仑样反应）
8. 复方磺胺甲噁唑（复方新诺明）的主要适应证有哪些？（→ 尿路感染、肺孢子菌肺炎（PCP）、伤寒、痢疾等）
