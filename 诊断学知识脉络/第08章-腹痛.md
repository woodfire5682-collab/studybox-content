## 腹痛的定义与发生机制

**原理**：**腹痛**是由**腹部及邻近器官、腹壁、神经系统病变**引起的疼痛感觉，是最常见且病因复杂的症状。腹痛的神经机制包括**内脏痛**（腹腔内脏器病变，多为**钝痛、绞痛、定位模糊、伴植物神经症状、常位于腹中部**）、**躯体痛**（壁层腹膜、腹壁受刺激，**定位确切、锐痛、伴压痛反跳痛、可随体位变化**）与**牵涉痛（放射痛）**（内脏病变放射至特定体表，如胆囊炎→右肩，胰腺炎→左腰背，肾绞痛→下腹及会阴）。疼痛还可由**肠管平滑肌痉挛（绞痛）、缺血、炎症、梗阻、穿孔、出血**等引起。

**影响因素**：病变器官与性质（炎症、梗阻、缺血、穿孔、出血、肿瘤）、疼痛类型（内脏痛/躯体痛/牵涉痛）、部位（腹痛的解剖定位）、起病缓急（急性/慢性）、诱因（进食、空腹、体位、运动）、伴随症状（发热、恶心呕吐、腹泻、血尿、黄疸、黑便）、年龄与性别、既往病史。

**反向思考**：
- **腹痛的本质是"多因一症"**，不能一上来就按"胃痛/肠炎"处理——**急性腹痛的"红旗征"（急性胰腺炎、穿孔、肠梗阻、肠系膜缺血、宫外孕破裂、主动脉瘤破裂、急性心梗）**要先行排除，**避免"先止痛后查因"掩盖病情**。
- **内脏痛定位模糊、常在脐周/上腹正中**，只有病变累及壁层腹膜才出现**定位明确的压痛、反跳痛、肌紧张（腹膜刺激征）**——**腹膜刺激征是外科急腹症与内科腹痛的"分水岭"**。
- **腹痛 + 休克（面色苍白、冷汗、血压下降）** → 警惕**内出血（宫外孕破裂、脾破裂、主动脉瘤破裂）、急性胰腺炎、肠系膜缺血、中毒型菌痢**——休克是紧急征象。
- **牵涉痛可误导诊断**：下壁心梗可表现为上腹痛/剑突痛（"胃痛性心梗"）；膈肌刺激（下叶肺炎）放射右肩；胆囊炎放射右肩背部；肾绞痛放射至会阴——**凡"上腹痛+胸闷/出汗"或"右肩痛"要想到心源性/胸源性**。
- **老年人、糖尿病、免疫抑制者的腹痛可不典型**（反应差、甚至无痛性急腹症），症状轻而病变重——不能因"痛得不重"而放松警惕。

**实际例子**：中年男性突发**上腹剧痛向腰背部放射、持续性、伴恶心呕吐、进食后加重** → **急性胰腺炎**（血清淀粉酶/脂肪酶升高）；青年女性**停经+下腹痛+阴道出血+晕厥** → **异位妊娠破裂（宫外孕）**——腹痛的"红旗"急症。

## 腹痛的病因与分类（急慢性）

**原理**：按病程分**急性**（急性起病：急腹症——急性阑尾炎、胆囊炎、胰腺炎、肠梗阻、溃疡穿孔、胆管炎、肾绞痛、宫外孕、腹主动脉瘤破裂、肠系膜缺血、胃肠炎）与**慢性**（间歇/持续，>3 个月：消化性溃疡、慢性胃炎/胆囊炎/胰腺炎、溃疡性结肠炎、克罗恩病、功能性胃肠病、肠易激综合征、肿瘤）。急性与慢性腹痛的病因谱不同，急性以**急腹症与感染**为主，慢性以**溃疡、功能性、慢性炎症、肿瘤**为主。

**影响因素**：起病缓急、腹腔器官病变性质、年龄与性别（青年女性警惕宫外孕、泌尿系感染；老年警惕缺血、肿瘤）、部位、诱因与缓解因素、伴随症状（发热、呕吐、腹泻、血便、黄疸、血尿、停经）、既往史（溃疡病、胆石症、糖尿病、心血管病、腹部手术史）。

**反向思考**：
- **急性腹痛"先问病史+查体+急查血尿淀粉酶/腹部立位平片/超声/CT"**，不能轻易就"给止痛药压下去"；**无明确肠道外病因的急性剧烈腹痛**要考虑**急性胰腺炎、肠系膜缺血、穿孔、不全梗阻、宫外孕、主动脉夹层**。
- **转移性右上腹痛**（先脐周/上腹，逐渐转移/固定于右下腹）是**急性阑尾炎**的典型过程——**"转移性右下腹痛"是经典，但老人、儿童、孕妇不典型，极易误诊**。
- **空腹痛/夜间痛、进食缓解** → **十二指肠溃疡**；**餐后痛/空腹减轻** → **胃溃疡**；**进食后加重、呕血/黑便、消瘦** → **胃癌**——**疼痛与进食的关系**是慢性腹痛最重要的定位线索之一。
- **腹痛 + 腹泻黏液脓血便 + 里急后重** → 溃疡性结肠炎/菌痢；**腹痛 + 腹泻便秘交替 + 大便变细 + 消瘦 + 贫血** → 结直肠癌/肠易激综合征——**大便习惯改变 + 消瘦贫血是肿瘤报警**。
- **腹痛 + 血尿 + 向会阴放射** → **泌尿系结石**；**停经后腹痛 + 阴道出血** → **宫外孕**（妇产科急症）；**右下腹 / 右上腹压痛 + 发热** → 阑尾炎/胆囊炎——**按部位查邻系统**。

## 腹痛的部位与性质（定位意义）

**原理**：腹痛的**部位**最能指示病变器官（腹部分区），**性质**（绞痛、钝痛、胀痛、烧灼样、刀割样、撕裂样、钻顶样）与**转移/放射**进一步提示病种。

**影响因素**：病变器官所在分区、病变性质（绞痛：空腔脏器痉挛/梗阻，如胆绞痛、肾绞痛、肠绞痛；钝痛/隐痛：实质脏器或炎症；烧灼样：胃酸/溃疡；刀割样：穿孔/急性胰腺炎/夹层；撕裂样：主动脉夹层；钻顶样：胆道蛔虫）、起病急缓、有无放射、性别年龄、伴随症状。

**反向思考**：
- **中上腹/剑突下痛** → 胃十二指肠、胰腺、胆道、下壁心梗；**右上腹** → 肝、胆；**左上腹** → 脾、胰腺尾；**右下腹** → 阑尾、回盲、右侧输尿管、妇科；**左下腹** → 乙状结肠、左侧输尿管、妇科；**脐周** → 小肠（早期）、肠绞痛；**下腹（耻骨上）** → 膀胱、子宫、直肠。
- **侧腹/腰背部痛 + 放射至会阴/腹股沟** → **肾/输尿管绞痛**；**上腹束带样放射至腰背** → **急性胰腺炎**（左腰背）；**右肩放射** → **胆囊炎/膈下病变**；**左肩放射** → **脾破裂/心梗**——**放射痛是"牵引"线索**。
- **撕裂样/刀割样持续剧烈腹痛，向背部/肾区放射，伴休克** → **主动脉夹层/急性胰腺炎/a 型夹层**；**阵发性绞痛 + 腹胀 + 呕吐 + 停止排气排便** → **肠梗阻**；**钻顶样、突发骤止、感"顶"** → **胆道蛔虫症**。
- **"痛死人的腹痛"患者**：**急性腹主动脉夹层（撕裂样）、急性胰腺炎（刀割样）、肠系膜血管栓塞（腹部剧痛与体征不符）**——三者是极易漏诊、危重的腹痛，早期识别是救命关键。

**实际例子**：50 岁男性高血压史，突发**撕裂样胸腹剧痛向背部放射、双上肢血压不对称、休克** → **主动脉夹层**；中年女性**右上腹绞痛（阵发、可向右肩放射）+ 进食油腻后加重 + 发热黄疸** → **胆结石/急性胆囊炎**。

## 腹痛的伴随症状与诊断鉴别

**原理**：伴随症状帮助缩小病因、判断病情轻重与并发症：发热（炎症/感染）、恶心呕吐（梗阻/炎症）、腹泻黏液脓血便（肠炎/结肠炎/菌痢）、血便（下消化道出血/缺血/肿瘤）、黄疸（肝胆胰病变）、血尿（泌尿系结石/感染）、停经（妊娠相关）、腹胀/停止排气排便（肠梗阻）、休克（内出血/重症感染/缺血）、腰背痛放射（胰腺炎/夹层）。

**影响因素**：病种、病变性质、是否有并发症（穿孔、梗阻、出血、休克）、年龄与性别、病程阶段、全身状态。

**反向思考**：
- **腹痛 + 发热**：先发热后腹痛（腹外、内科炎症——肺炎、胸膜炎、心梗）；先腹痛后发热（外科急腹症——阑尾炎、胆囊炎、胰腺炎穿孔）；**先发热后腹痛+右下腹**要注意**肺炎（下叶）**——"胸源性腹痛"。
- **腹痛 + 呕吐 + 腹胀 + 停止排气排便**（痛、吐、胀、闭四联征） → **肠梗阻**；**腹痛 + 呕血黑便** → 上消化道出血/胃癌；**腹痛 + 血便** → 下消化道/肠套叠/缺血性结肠炎。
- **腹痛 + 黄疸（Charcot 三联征：腹痛、发热、黄疸）** → **急性化脓性胆管炎（Reynolds 五联征+休克+神志）**——外科急重症；**腹痛 + 黄疸 + 消瘦** → 胰头癌/壶腹癌（Courvoisier 征：无痛进行性黄疸+可触及肿大胆囊）。
- **腹痛 + 全部腹膜刺激征 + 气腹（立位膈下游离气体）** → **消化道穿孔（溃疡、肠穿孔）**。
- **内科腹痛 vs 外科腹痛**：内科（功能、炎症较轻，无腹膜刺激征、无休克、体征与症状可分离）与外科（急腹症：有手术指征、腹膜刺激征、高热/休克、进行性加重）——**出现腹膜刺激征、休克、气腹、血性腹水提示外科/重症，需外科评估**。

### 内科腹痛 vs 外科腹痛对比表

| 对比项 | 内科（功能/炎性）腹痛 | 外科（急腹症）腹痛 |
|---|---|---|
| 起病 | 多缓、反复、与进食/情绪相关 | 多急骤、持续性加重 |
| 腹膜刺激征 | 无或轻（无反跳痛） | 常有压痛+反跳痛+肌紧张 |
| 休克 | 一般无 | 可出现（内出血、重症感染、缺血） |
| 全身中毒 | 轻 | 高热、败血症、神志改变 |
| 与进食/体位 | 常有明确诱因与缓解 | 与诱因关系小、持续加重 |
| 典型病种 | 溃疡病、功能性、慢性胃炎/胆道 | 阑尾炎、胆囊炎、胰腺炎、穿孔、肠梗阻、宫外孕 |
| 决策 | 保守/对症 | 常需外科干预 |

## 腹痛的问诊要点

**原理**：问诊的目的是**确定疼痛的部位、性质、起病、诱因、放射、伴随症状与缓解方式**，结合**年龄、性别、既往史**，为鉴别诊断与紧急分层提供依据。必须问清**痛在哪、怎么痛、何时开始、什么诱发、什么缓解、向哪里放射、伴什么、发病前后情况**。

**影响因素**：患者对疼痛描述的能力、部位与性质的准确性、既往史（溃疡、胆石、糖尿病、心血管病、手术史）、用药史（NSAIDs、抗凝）、月经生育史（女性）、伴随症状、危险因素（吸烟、饮酒、年龄）。

**反向思考**：
- **"痛的性质 + 部位 + 放射 + 伴随"是腹痛诊断的"四要素"**，问诊时避免遗漏**月经史、手术史、糖尿病史、心血管病史**——这些是宫外孕、粘连性肠梗阻、无痛性心梗、缺血性腹痛的"暗雷"。
- **腹痛的"红旗"问诊**：**突发剧烈腹痛、腹膜刺激征、休克、气腹、血性腹水、停经+阴道出血、腹部搏动性包块、血压不对称**——出现首先考虑急症/外科/血管性，勿按普通腹痛处理。
- 问诊要追问**"是否做过腹部手术、近期是否抗凝/服 NSAIDs、有无糖尿病/心血管病、女性是否停经"**——这些直接影响急腹症与缺血性/出血性腹痛的判断。
- **"一年来反复腹痛未明"** → 警惕**功能性胃肠病、IBD（克罗恩/溃疡性结肠炎）、慢性胰腺炎、肿瘤、肠系膜缺血、胆道疾病**——需系统排查而非反复"对症用药"。

**实际例子**：一名**60 岁男性、糖尿病史、突发剧烈腹部绞痛、恶心、腹泻**，腹痛重而体征轻、血乳酸高 → **急性肠系膜缺血**（需急诊血管影像），这类"体征与症状不符"的腹痛最危险。

## 反向思考·自测题（本章核心）

1. 腹痛首先应排除哪些"红旗"急症？（→ 急性胰腺炎、穿孔、肠梗阻、肠系膜缺血、宫外孕破裂、主动脉瘤/夹层破裂、急性心梗）
2. 什么是腹膜刺激征？其出现提示什么？（→ 压痛+反跳痛+肌紧张，提示壁层腹膜受累，多为外科急腹症）
3. 为什么"先腹痛后发热"vs"先发热后腹痛"有诊断意义？（→ 先腹痛后发热多为外科急腹症；先发热后腹痛多为内科感染/胸源性（下叶肺炎））
4. 转移性右下腹痛提示什么？为何需警惕不典型？（→ 急性阑尾炎；老人儿童孕妇不典型易误诊）
5. 空腹痛/夜间痛、进食后痛分别提示什么？（→ 十二指肠溃疡、胃溃疡；也需排除胃癌）
6. 腹痛+右上腹绞痛+黄疸+发热是什么？（→ Charcot 三联征→急性化脓性胆管炎，可进展为 Reynolds 五联征）
7. 撕裂样/刀割样腹痛向背部放射伴休克提示什么？（→ 主动脉夹层或急性胰腺炎）
8. 为何"腹痛重但体征轻"要警惕肠系膜缺血？（→ 症状与体征不符、血乳酸升高，需急诊血管影像）
9. 女性停经后腹痛+阴道出血要想到什么？（→ 异位妊娠（宫外孕）破裂，需紧急处理）

> 记忆口诀：**腹痛多因一症察，红旗先排危重症；内脏钝痛定位糊，躯体锐痛腹膜征；部位定位剖一剖，剑下胃胰胆心，右上肝胆左上脾，右下阑尾回盲输尿管，左下乙状妇科侧，脐周小肠脐下盆；绞痛空腔梗阻、刀割穿孔胰腺，撕裂夹层钻顶蛔虫；故先问牲（性质部位放射伴随）、后查因，停经手术糖尿病、心血管病别藏雷。**
