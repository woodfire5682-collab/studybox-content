## 胸痛的定义与发生机制

**原理**：**胸痛**指胸部的疼痛感觉，可由**胸壁、胸内脏器、纵隔、肩部及牵涉（放射）**部位的病变引起。疼痛的发生与**组织缺血缺氧（心肌、肺）、炎症、机械压迫、肿瘤浸润、神经刺激**等有关。**牵涉痛**是胸痛的重要机制——内脏病变（如心绞痛、胆囊炎）在远离病变的体表区域产生疼痛（心源性痛可放射至左肩、左臂、下颌、颈部，胆囊/膈肌病变放射至右侧肩部）。

**影响因素**：病变部位（心、肺、胸壁、食管、大血管）、性质（刀割样、烧灼样、压榨样、隐痛）、强度、持续时间、诱因（活动、呼吸、体位、吞咽、情绪）、缓解方式（休息、硝酸甘油、体位）、人群易感因素（性别、年龄、冠心病/高血压/糖尿病、吸烟）。

**反向思考**：
- **胸痛最基本的鉴别是"危及生命的胸痛"优先**：**心肌梗死、主动脉夹层、肺栓塞、张力性气胸、食管破裂**是"致命五联"，必须先排除，再考虑良性的肌骨骼/胸壁/神经性疼痛——**"先救命，后鉴别"**是胸痛核心。
- **心绞痛 vs 心梗**：**心绞痛**为**休息或含服硝酸甘油可缓解**的压榨样胸骨后痛，持续 **1~5 分钟**；**心梗**为**持续＞30 分钟、含硝酸甘油不缓解**的剧烈压榨样/濒死感疼痛——**"能否用硝酸甘油缓解"**是现场快速判断要点。
- **胸壁痛 vs 内脏痛**：胸壁（肋骨、肋软骨、神经、肌肉）疼痛**可被按压复制、与呼吸/体位/活动相关、多有明确压痛点**；内脏性心痛则**按压无明确压痛点、与活动/情绪相关**——"按压能否加重"是重要鉴别。
- **主动脉夹层**为**撕裂样、刀割样剧痛，起始即最重，可向背部/腰部放射**，常见于高血压史中年男性——与心梗（压榨样、渐重）性质不同。
- **胸痛伴呼吸困难、发绀、休克**提示肺栓塞、气胸、大面积心梗/夹层；**伴发热、咳嗽**提示肺/胸膜感染——伴随症状决定定位。
- **烧灼样胸痛伴反酸、与进食/卧位有关**提示**胃食管反流病（GERD）**，可有与心绞痛相似的胸骨后痛，勿误判为心脏病。

**实际例子**：50 岁男性突发**胸骨后压榨样剧痛、向左肩和下颌放射、持续 1 小时、含硝酸甘油不缓解、大汗** → **急性心肌梗死**；而年轻女性**胸骨后烧灼痛、平卧加重、进食后明显、含硝酸甘油无效** → **胃食管反流病**——二者疼痛位置相似但机制与处理截然不同。

## 胸痛的病因与分类

**原理**：按来源分五大类：① **胸壁疾病**（肋软骨炎、肋骨骨折、带状疱疹、胸壁软组织炎症、肋间神经痛）；② **心血管疾病**（心绞痛、心梗、心包炎、心肌炎、主动脉夹层、主动脉瘤、肺栓塞）；③ **呼吸系统**（胸膜炎、自发性气胸、肺炎、肺癌、肺结核）；④ **纵隔与食管疾病**（食管炎、GERD、食管癌、纵隔肿瘤/炎症）；⑤ **其他**（膈下脓肿、带状疱疹前驱痛、神经精神性）。

**影响因素**：年龄、性别与危险因素（高血压、糖尿病、吸烟、高脂血症——冠心病）；诱因（活动、呼吸、体位、吞咽、情绪、免疫力下降）；伴随症状；疼痛性质、部位与放射。

**反向思考**：
- **带状疱疹**的**疼痛先于皮疹**（前驱期 3~5 天），可呈"刀割样、烧灼样"被误为心绞痛/心梗——**皮肤单侧、沿肋间分布、伴感觉过敏**是线索，出疹后即明确。
- **心包炎**疼痛**随吸气、体位改变（前倾坐位减轻）**，伴心包摩擦音——与心绞痛"活动诱发、休息缓解"不同。
- **肺栓塞**胸痛+呼吸困难+咯血+单侧下肢肿，**突发、与体位无关、伴发绀/晕厥**——极易被忽略，需 D-二聚体筛查。
- **神经精神性/功能性胸痛**（焦虑、过度通气、心脏神经症）多在**情绪波动时、部位不定、性质多变、无器质体征**——但**必须先全面排除器质性**，不能轻易给"植物神经紊乱"诊断。
- **女性、糖尿病的胸闷痛可不典型**（心梗症状常不典型甚至无痛），**无痛性心肌缺血**在糖尿病患者中并不少见。

**实际例子**：糖尿病患者**上腹不适、呕吐而非典型胸痛**，心电图示 ST 段抬高 → **无痛性心肌梗死**；一个"胸痛+发热+前倾坐位减轻+心包摩擦音"的年轻人 → **急性心包炎**。

## 心悸的定义与发生机制

**原理**：**心悸**是一种**自觉心脏跳动的不适感**（心慌、心搏有力、心跳加快/停顿/加重），可源于**心动过速、心动过缓、心律失常、心搏增强、神经精神因素**。可伴或不伴**器质性心脏病**。其机制涉及**心率异常、节律异常、每搏输出量改变、交感神经兴奋**等。

**影响因素**：心率与节律改变、心肌收缩力（甲亢、贫血、运动）、自主神经兴奋（情绪、焦虑、咖啡/茶/尼古丁）、药物（阿托品、麻黄碱、咖啡因、烟酒）、全身状态（发热、贫血、低血糖、甲亢）、有无基础心脏病、年龄与性别。

**反向思考**：
- **心悸 ≠ 心律失常**，**心律失常 ≠ 心悸**：心悸可以是**窦性心动过速、期前收缩（早搏）、阵发性心动过速、房颤**等各种原因，也可能是**功能性（焦虑、神经症、生理性）**——**不能仅凭"心慌"就下"心律失常"诊断**。
- **心悸的病理生理意义**：**心悸 + 脉搏缓慢（＜40 次/分）**提示**心动过缓（房室传导阻滞、病态窦房结）**；**心悸 + 脉搏快而不规则**提示**心房颤动**；**心悸 + 发作性、突发突止（节律整齐、心率快）**提示**阵发性室上性心动过速**——脉搏节律与心率是定性关键。
- **"早搏"的心悸多为"猛然心跳一下、间歇感"**，多属**室性/房性期前收缩**，多数为良性，但频发者需查心电生理与器质病因。
- **心悸 + 多食、多汗、消瘦、心率快** → **甲亢**；**心悸 + 乏力、贫血貌、活动后气短** → **贫血**；**心悸 + 低血糖（饥饿、出汗、手抖）** → **低血糖**——要从全身代谢找病因，不能只盯心脏。
- **心脏神经症（功能性心悸）**：青年女性，情绪事件诱发，**心悸 + 胸闷 + 叹气样呼吸 + 焦虑**，运动后反而减轻，心电图无器质改变——但需排除器质性。

**实际例子**：30 岁男性**心悸、脉搏触而不齐、快慢不一（脉率＜心率）** → **心房颤动**；年轻女性**情绪紧张后心悸、气短、叹气、查体与心电图正常** → **心脏神经症**（功能性）——一个器质性疾病，一个功能性症状。

## 心悸的病因与伴随症状/问诊要点

**原理**：心悸的病因可分为**心源性**（心动过速/过缓、心律失常、心肌病、心瓣膜病、心衰、心肌炎）与**非心源性**（甲亢、贫血、发热、低血糖、嗜铬细胞瘤、精神心理、生理性+诱因如咖啡/烈酒/烟/运动、药物）。问诊要点是**心悸的起病缓急、诱因、持续时间、频率与节律、伴随症状（胸闷、胸痛、头晕、晕厥、气促）、基础心脏病史、用药史与吸烟饮茶/咖啡史**。

**影响因素**：诱发因素（情绪、运动、咖啡茶烟、药物、饮酒）、伴随症状、基础病（高血压、冠心病、甲亢、贫血、心衰）、发作是否突发突止、有无伴晕厥/黑矇（危险信号）、年龄性别。

**反向思考**：
- **心悸 + 晕厥 / 近晕厥（黑矇）**是**危险信号**，提示**严重心律失常（恶性室性心律失常、房室传导阻滞、SSS）**或低心排——要紧急监护与评估，不是普通"心慌"。
- **心悸伴胸痛**需鉴别（心律失常引起冠脉供血不足、心梗伴心律失常、夹层、肺栓塞）——胸痛与心悸合并提示较重。
- **突发突止、节律整齐**的心动过速提示**阵发性室上性心动过速**；**快而不规则**提示**房颤**；**慢而规则**提示**窦性心动过缓**——**用手轻轻搭脉（脉律+脉率）**常先于心电图给出方向。
- 问诊要问**近期是否服用可致心悸的药物**（拟交感药、茶碱、甲状腺素、抗抑郁药、含咖啡因制剂）以及**是否吸烟、浓茶、咖啡、饮酒**——"诱因"远比"心慌"本身重要。

**实际例子**：一名患者近半年**反复心悸、消瘦、多汗、怕热、心率 120 次/分** → **甲状腺功能亢进**（心源性外的常见病因）；饮酒/浓茶后"心慌"为生理性，停用诱因即可，无需长期抗心律失常。

## 反向思考·自测题（本章核心）

1. 胸痛首先要排除哪几种致命性疾病？（→ 心肌梗死、主动脉夹层、肺栓塞、张力性气胸、食管破裂）
2. 心绞痛与心肌梗死的疼痛如何区分？（→ 心绞痛休息或含硝酸甘油 1~5 分钟缓解；心梗持续＞30 分钟、含药不缓解、濒死感）
3. 如何鉴别胸壁痛与内脏性胸痛？（→ 按压能否复制、与呼吸/体位/活动关系、有无明确压痛点）
4. 主动脉夹层的疼痛有何特征性？与心梗有何不同？（→ 撕裂样刀割样、起始即最重、向背部放射；心梗为压榨样逐渐加重）
5. 为什么烧灼样、进食后加重的胸骨后痛要想到 GERD？（→ 易与心绞痛混淆，需问反酸、平卧加重、含硝酸甘油无效）
6. 心悸一定提示心律失常吗？举例说明。（→ 不一定，可为窦性心动过速/功能性/甲亢/贫血/低血糖/心脏神经症等）
7. 心悸+晕厥为何危险？（→ 提示恶性心律失常/严重传导阻滞/低心排，需紧急评估）
8. 如何仅凭搭脉就初步判断心悸类型？（→ 快而不规则→房颤；突发突止整齐快速→阵发性室上速；慢而不齐→传导阻滞）
9. 心悸伴多食多汗消瘦提示什么？（→ 甲状腺功能亢进）

> 记忆口诀：**胸痛先排致命五，心梗夹层肺栓气胸食管破；压榨含药缓是心绞痛，持续不缓是心梗；撕裂夹层向背放，按压能加重是胸壁；心悸莫皆心律失常，快而不规房颤，突止整齐室上速，慢而不齐传导滞，心悸晕厥要警醒。**
