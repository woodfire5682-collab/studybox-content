## 腹泻的定义与发生机制

**原理**：**腹泻**指**排便次数增多、粪便稀薄（水分增加）或含黏液脓血**，通常**每日排便 >3 次或粪便含水量 >200 ml/d**。发生机制有四类：① **渗透性腹泻**（高渗性物质致肠内渗透压升高——乳糖不耐受、盐类泻剂、吸收不良）；② **分泌性腹泻**（肠道主动分泌水电解质增多——霍乱、产毒性大肠埃希菌、分泌性肿瘤如 VIP 瘤）；③ **渗出性（炎症性）腹泻**（肠黏膜炎症受损致渗出——痢疾、溃疡性结肠炎、克罗恩病）；④ **动力异常性腹泻**（肠蠕动过快——IBS、甲亢、神经性）。多数腹泻为**混合机制**。

**影响因素**：病因（感染性[细菌、病毒、寄生虫]、炎症性[IBD]、肿瘤性、吸收不良性、药物性、内分泌性、功能性[IBS]、饮食）、病程（急性 <2 周；慢性 >4~8 周）、粪便性状与量（水样、黏液脓血、脂肪泻）、有无脱水/电解质紊乱、伴随症状（发热、腹痛、里急后重、营养不良、体重下降）、年龄与基础免疫。

**反向思考**：
- **急性 vs 慢性腹泻**病因谱不同：**急性**多为**感染性/食物中毒/菌痢/急性胃肠炎**；**慢性**多为**炎症性肠病（IBD）、吸收不良、肠道肿瘤、内分泌性（甲亢）、肠易激综合征、功能性**——慢性腹泻不能简单当"肠炎反复"。
- **渗透性 vs 分泌性腹泻**的鉴别要点：**禁食后渗透性腹泻减轻、分泌性腹泻不减轻**；**分泌性腹泻量大、水样、量大不因禁食而减少**——**"禁食后是否缓解"是关键**。
- **黏液脓血便 + 里急后重 + 腹痛** → **痢疾、溃疡性结肠炎、感染性结肠炎**；**水样大量腹泻** → **分泌性（霍乱、产毒素菌）、病毒性胃肠炎**；**脂肪泻（量大、油亮、恶臭、漂浮）** → **吸收不良（胰腺性、小肠吸收障碍、乳糜泻）**——粪便性状是"分型名片"。
- **"腹泻+便秘交替"** → **肠易激综合征（IBS）、结直肠癌、克罗恩病**——要考虑肿瘤与 IBD，勿轻易归为"肠功能紊乱"。
- **老年人、免疫抑制、婴幼儿、慢性病者**腹泻易致**脱水和电解质紊乱（低钾、低氯）、休克、酸中毒**——**急性腹泻要评估脱水与循环状态**，不能只对症止泻。
- **"抗生素相关性腹泻/艰难梭菌感染"**：近期使用广谱抗生素后腹泻、多为大量水样便、可伴伪膜（伪膜性肠炎）——需警惕，勿再用抗生素。

**实际例子**：进食不洁后**水样腹泻、呕吐、发热** → **急性胃肠炎/感染性腹泻**；反复**黏液脓血便、里急后重、腹痛** → **溃疡性结肠炎**——二者都是"拉肚子"但机制与处理不同。

## 腹泻的病因与分类

**原理**：按病程分**急性**（感染性、食物中毒、菌痢、急性胃肠炎、药物性）与**慢性**（炎症性肠病 IBD[克罗恩、溃疡性结肠炎]、感染性肠炎、吸收不良综合征、肠道肿瘤、内分泌性[甲亢、VIP 瘤]、糖尿病性腹泻、药物性、肠易激综合征、功能性）；按机制分**渗透性、分泌性、渗出性、动力异常性**。

**影响因素**：病程、病因（感染、炎症、肿瘤、吸收不良、内分泌、药物、功能）、粪便性状（水样、黏液脓血、脂肪泻、泡沫状）、有无脱水、伴随症状（发热、腹痛、体重下降、营养不良）、伴发疾病（糖尿病、免疫抑制）、用药史（抗生素、泻药、含镁药物、质子泵抑制剂、化疗药）、饮食与旅行史。

**反向思考**：
- **急性腹泻的"红旗"**：高热、血水样便（重症感染/痢疾/肠出血性大肠埃希菌）、剧烈腹痛（急腹症可能）、少尿脱水、老年人/婴幼儿/免疫抑制、近期抗生素（伪膜性肠炎）——**要查便常规与便培养，评估脱水**。
- **慢性腹泻三大类**（**炎症性、分泌性、渗透性/吸收不良性**）要先分型：**黏液脓血、里急后重→炎症性（IBD、感染性肠炎）**；**水样大量、禁食不止→分泌性（VIP 瘤、霍乱）**；**脂肪泻、腹泻-便秘交替→吸收不良/动力性**。
- **慢性腹泻 + 体重下降 + 贫血 + 低白蛋白** → 警惕**IBD、肠道肿瘤（结直肠癌、淋巴瘤）、吸收不良、结核性肠炎**——不能只按"肠胃功能不好"处理。
- **"慢性腹泻"要追问"是否长期服泻药/减肥药/含镁抗酸剂/质子泵抑制剂/抗生素、是否糖尿病、甲亢"**——药物性、内分泌性常被忽略。
- **腹泻 + 心悸、多汗、消瘦、怕热** → **甲亢**（动力性腹泻）；**腹泻 + 低血糖、皮肤色素沉着、乏力、电解质紊乱** → **肾上腺皮质功能减退**（少见但重要）。

**实际例子**：近期服**抗生素**后出现**大量水样腹泻、发热** → **艰难梭菌/伪膜性结肠炎**；**腹泻+消瘦+心悸+多汗+怕热** → **甲亢性腹泻**。

## 腹泻的伴随症状与问诊要点

**原理**：伴随症状帮助定位：发热（感染/炎症）、腹痛（炎症/梗阻/功能性）、里急后重（直肠刺激——痢疾、溃疡性直肠炎、IBD）、恶心呕吐（急性胃肠炎、梗阻）、消瘦体重下降（吸收不良、肿瘤、IBD、甲亢）、贫血（慢性失血、吸收不良）、脱水（重症）、便秘交替（IBS、肿瘤）。问诊要点是**病程、次数、性状与量、与进食/药物关系、有无腹痛/里急后重/发热/消瘦、旅行史与饮食习惯、近期抗生素/泻药/减肥药、伴发疾病（糖尿病、甲状腺病）、粪便有无血/黏液/脓**。

**影响因素**：病因、病程、伴随症状、粪便性状、年龄、饮食与旅行史、用药史、基础病、免疫状态、脱水和电解质状况。

**反向思考**：
- **腹泻 + 发热 + 黏液脓血便 + 里急后重** → **细菌性痢疾/IBD/感染性结肠炎**；**腹泻 + 餐后加重 + 恶心呕吐** → **急性胃肠炎/胃动力异常**；**腹泻 + 糖尿病/消瘦/神经病变** → **糖尿病性腹泻**。
- **"里急后重"提示直肠受刺激**（痢疾、直肠炎、IBD、直肠癌、盆腔病变）——这是把腹泻定位到"左半结肠/直肠"的重要线索。
- **旅行者腹泻**：到发展中国家后急性水样腹泻，多为产毒性大肠埃希菌/病毒——多为自限，但需补水。
- **问诊必须问"禁食后缓解吗？量多少？有无血、脓、黏液？有无体重下降？"** ——这些都决定**分型（渗透/分泌/渗出/动力）与紧迫性**。
- **慢性腹泻伴出血、贫血、消瘦** → **结直肠癌/IBD**必须行**结肠镜**排查。

**实际例子**：中年男性**腹泻黏液脓血便、里急后重、反复发作、间歇缓解、消瘦** → **溃疡性结肠炎**（需结肠镜+活检）；患者**水样腹泻量大、禁食不缓解、血便、高热** → **重型感染性肠炎/霍乱样腹泻**（需补液+抗菌），二者"拉肚子"的表现与严重度差异巨大。

## 便秘的定义与发生机制

**原理**：**便秘**指**排便次数减少（每周 <3 次）、粪便干硬、排便困难（用力、不尽感、堵塞感、肛门阻塞、便时疼痛或需手法辅助）**。发生机制涉及**结肠传输减慢、直肠排便障碍（出口梗阻）、排便反射异常、精神因素**等。分**功能性**（最常见——不良饮食饮水、缺乏活动、精神紧张、长期抑制便意、盆底肌功能失调）与**器质性**（肠梗阻、肿瘤、炎症狭窄、内分泌/代谢疾病[甲减、糖尿病]、神经系统疾病、药物[阿片类、钙拮抗剂、抗胆碱能药、含铝抗酸剂]、妊娠、腹肌无力）。

**影响因素**：饮食（纤维素与水分不足）、活动量、精神心理、滥用泻药、排便习惯抑制、器质病变（肠道梗阻/肿瘤、盆底、神经、内分泌）、药物（阿片、钙拮抗剂、抗胆碱、铁剂、利尿剂、含铝/钙抗酸剂）、年龄（老年）、妊娠、代谢病（甲减、糖尿病）、严重营养不良与脱水。

**反向思考**：
- **便秘不等于"肠道功能紊乱"**——**器质性便秘（肠梗阻、肿瘤、狭窄）需要排除**：**便秘 + 大便变细/变扁 + 便血 + 贫血 + 消瘦 + 进行性加重** → 警惕**结直肠癌**；**便秘 + 腹痛腹胀 + 呕吐 + 停止排气排便** → **肠梗阻**——**"进行性 + 报警症状"是肿瘤/梗阻信号**。
- **功能性便秘 vs 器质性**：功能性多为**长期、与饮食/情绪/生活习惯相关、无消瘦贫血、无便血**；器质性多**近期出现、进行性、伴报警症状**——**新发/进行性便秘 + 报警症状要行肠镜**。
- **便血 + 便秘（老年）**：既有**痔/肛裂**（排便时疼痛、鲜血附着），也可能为**结直肠癌**——**中老年便秘+便血必须排除肿瘤**，勿只当"痔、肛裂"。
- **腹泻便秘交替** → **IBS、结直肠癌、克罗恩病**——不可掉以轻心。
- **便秘 + 顽固性、长期用泻药无效或加重** → **出口梗阻型便秘（盆底肌、直肠前突、内套叠、耻骨直肠肌痉挛）**——需**排便造影/盆底功能检查**，与慢传输型不同。
- **药物性便秘**（阿片类、钙拮抗剂、抗胆碱能药）是常见可逆原因——**问用药史**比反复吃泻药更重要。

**实际例子**：75 岁男性**近期排便困难、大便变细、伴暗红血便、贫血、消瘦** → **结直肠癌**（需结肠镜）；年轻女性**长期便秘、久坐、饮水少、偶用刺激性泻药，无消瘦贫血** → **功能性便秘**——一种是器质性需手术/筛查，一种是功能性可调整生活。

### 腹泻与便秘关键对比表

| 对比项 | 腹泻 | 便秘 |
|---|---|---|
| 定义 | 排便次数增多、粪便稀薄、>3 次/日或含水 >200ml/d | 排便次数减少（<3 次/周）、干硬、排便困难 |
| 常见机制 | 渗透性、分泌性、渗出性、动力异常性 | 结肠传输减慢、出口梗阻、排便反射异常 |
| 急性病因 | 感染性、食物中毒、菌痢、急性胃肠炎 | 器质性梗阻、药物、生活方式 |
| 慢性病因 | IBD、吸收不良、肿瘤、内分泌、IBS | 功能性（最常见）、器质性（肿瘤、狭窄、神经内分泌、药物） |
| 报警症状 | 血便、高热、脱水、消瘦、贫血 | 便血、贫血、消瘦、大便变细、进行性加重 |
| 伴随警示 | 里急后重（直肠刺激） | 停止排气排便（肠梗阻）、腹痛腹胀 |
| 危险信号 | 紧急补液避免脱水休克 | 排除梗阻与肿瘤 |

## 便秘的病因与问诊要点

**原理**：便秘病因分**功能性**（饮食饮水不足、活动少、精神紧张、习惯性抑制便意、盆底肌功能失调、滥用泻药）与**器质性**（肠道梗阻/肿瘤/狭窄、内分泌代谢（甲减、糖尿病）、神经系统（脊髓病变、自主神经）、药物、妊娠、腹肌无力、肛门直肠疾病（痔、肛裂、直肠脱垂、盆底病变））。问诊要点是**排便次数、粪便性状、排便困难程度、长期或近期、有无腹痛腹胀、有无便血、有无消瘦贫血、饮食饮水活动、精神与排便习惯、用药史（阿片、钙拮抗剂、抗胆碱、铁、含铝抗酸剂）、有无甲状腺/糖尿病、有无长期依赖泻药**。

**影响因素**：病因（功能性 vs 器质性）、病程（新发/进行性 vs 长期）、年龄（老年）、用药史、排便习惯与生活方式、伴发疾病、报警症状（便血、贫血、消瘦、大便变细、进行性加重）、肠道形态与盆底功能。

**反向思考**：
- **便秘问诊的"三问"**：**多久了？（近期新发 vs 长期）**、**有没有便血/贫血/消瘦？（报警）**、**有没有腹痛腹胀呕吐？（梗阻）**——这三问决定是"功能性，调整生活"还是"立刻排查器质性"。
- **新发便秘 + 大便变细/便血 + 消瘦贫血** → **结直肠癌**（报警）；**便秘 + 腹痛 + 呕吐 + 停止排气排便** → **肠梗阻**（紧急）。
- **便秘 + 怕冷、乏力、反应迟钝、体重增加、皮肤干燥、心率慢** → **甲状腺功能减退**（便秘是甲减常见表现，勿只当"肠胃问题"）。
- **"老便秘"长期用刺激性泻药（含蒽醌类）** → 可致**结肠黑变病、泻药依赖、结肠无力**——**滥用泻药本身就是便秘加重的病因**。
- **出口梗阻型便秘**：排便费力、有便意但排不净、需用手辅助、长期无效——需**盆底功能评估（排便造影、肛门直肠测压）**。

**实际例子**：中年女性**月经前后便秘加重、久坐、饮水少、无便血消瘦** → **功能性便秘**（调整饮食饮水、运动、规律排便）；老年男性**近期大便变细、便血、贫血消瘦** → **结直肠癌**（行结肠镜确诊）。

## 反向思考·自测题（本章核心）

1. 腹泻的四大发生机制是什么？各自代表什么腹泻类型？（→ 渗透性、分泌性、渗出性、动力异常性）
2. 如何鉴别渗透性与分泌性腹泻？（→ 禁食后渗透性腹泻减轻、分泌性不减轻；分泌性量大、水样、禁食不止）
3. 黏液脓血便+里急后重+腹痛提示什么？（→ 痢疾、溃疡性结肠炎、感染性结肠炎；里急后重提示直肠受刺激）
4. "腹泻与便秘交替"要警惕哪些病？（→ 肠易激综合征、结直肠癌、克罗恩病；勿轻易归为肠功能紊乱）
5. 为什么急性腹泻要评估脱水与循环状态、不能只止泻？（→ 老年人/婴幼儿/免疫抑制/慢性病者易脱水、电解质紊乱、休克、酸中毒）
6. 近期使用广谱抗生素后出现大量水样腹泻提示什么？（→ 艰难梭菌感染/伪膜性结肠炎）
7. 便秘有哪两大类型？器质性便秘的报警信号？（→ 功能性、器质性；新发/进行性、大便变细、便血、贫血、消瘦、腹胀呕吐停止排气排便）
8. 为什么中老年便秘+便血必须排除结直肠癌？（→ 既可为痔/肛裂，也可为肿瘤；报警症状需结肠镜）
9. 长期滥用刺激性泻药有什么危害？（→ 结肠黑变病、泻药依赖、结肠无力，加重便秘）
10. 便秘伴怕冷、乏力、体重增加提示什么？（→ 甲状腺功能减退）

> 记忆口诀：**腹泻水样次数多，机制四型渗分泌、渗出动力记心间；禁食不缓分泌性，脓血里急是炎症（直肠刺激）；水样量大想霍乱，脂肪油亮吸收差；慢性腹泻+瘦+贫血，IBD、肿瘤、结核查；便秘次数少干硬，功能多见器质藏；便细血瘦是报警，首排肠癌不冤枉；甲减便秘怕冷忘没，止泻先补液，通便先查因，泻药莫滥用。**
