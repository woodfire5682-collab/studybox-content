## 第一节 头部检查

**原理**：头部检查包括**头颅、眼、耳、鼻、口（口腔黏膜、舌、咽、扁桃体、腮腺）、面部及脑神经相关体征**。头部是感觉、运动、认知与内分泌（甲状腺、垂体）的重要部位，通过视、触、听、嗅可发现许多全身性疾病的特征性征象。

**影响因素**：光线是否充足、检查手法（触诊、视诊）、患者能否配合（睁眼、张口、伸舌）、器械（手电筒、压舌板、检眼镜、耳镜）、患者的意识与表情。

### 一、头颅与头发

**原理**：观察头颅**大小、形状**（小颅、巨颅、尖颅、方颅）、**头发**（分布、质地、脱发、白发）及**头部异常运动**（震颤、点头）。头颅的形状常提示发育与内分泌异常。

**影响因素**：遗传、营养、内分泌（甲状腺、垂体）、骨骼发育、年龄（婴幼儿囟门）。

**反向思考**：**方颅**（额、顶、颞隆起）见于佝偻病、先天性梅毒；**巨颅**（头颅增大、面小、额部突出）见于脑积水；**小颅**伴智力异常见于某些先天畸形（狭颅症）；**头部不自主震颤**见于震颤麻痹（帕金森病）、甲亢、肝胆疾病；**头发稀疏、干枯、脱发**见于营养不良、甲减、化疗、斑秃等。

**实际例子**：婴幼儿头颅显著增大、前囟膨隆、头皮静脉怒张、落日眼——**脑积水（巨颅）**。

### 二、眼

**原理**：检查**眼睑、眼球、结膜、巩膜、角膜、瞳孔、对光反射、调节反射、眼球运动与震颤**。瞳孔的大小、对称性、对光反射是判断神经系统与危重病情的重要指标。

**影响因素**：光线（检查瞳孔需适度光线）、患者睁眼配合、药物（阿托品散瞳、毛果芸香碱缩瞳）、年龄、眼睛局部病变。

**反向思考**：**双侧瞳孔不等大、一侧散大固定、对光反射消失**是**脑疝/严重颅内病变（脑卒中、颅脑外伤）**的危险信号，需紧急处理；**双侧瞳孔缩小（针尖样）**见于**有机磷中毒、镇静催眠药中毒、脑桥出血**；**双侧散大**见于**阿托品、氰化物、濒死状态**。**眼球突出**（双侧）提示**甲状腺功能亢进**；**单侧突眼**需警惕球后占位。**巩膜黄染**提示黄疸；**眼睑水肿**（晨起明显）见于**肾病、心衰、过敏**；**结膜苍白**提示贫血；**结膜充血**提示感染/结膜炎。**眼球震颤**见于**眩晕（前庭/中枢性）**及部分神经系统疾病；**瞳孔对光反射、调节反射**异常提示神经系统损害。

**实际例子**：意识障碍患者，左侧瞳孔散大、直接及间接对光反射消失、伴肢体偏瘫——提示**脑疝/急性脑卒中（颅内高压、瞳孔不等大）**，为危重急症。

### 三、耳、鼻、口（口腔、舌、咽、扁桃体、腮腺）

**原理**：**耳**查耳廓、外耳道（分泌物、流脓）、乳突压痛、听力；**鼻**查外形、鼻翼扇动、鼻腔通气与分泌物、鼻出血、鼻窦（额窦、上颌窦、筛窦）压痛；**口**查口唇、口腔黏膜、牙与牙龈、舌（舌苔、舌质、舌运动）、咽与扁桃体、口腔气味、腮腺、面神经（鼻唇沟、口角）。

**影响因素**：光线、器械（手电筒、压舌板、鼻镜、耳镜）、患者能否配合张口与伸舌、口腔清洁、局部病变与全身疾病。

**反向思考**：
- **口唇发绀**提示缺氧（心肺疾病）；**口唇疱疹**提示单纯疱疹或感染；**口角歪斜、鼻唇沟变浅**提示**面神经麻痹**——**周围性面瘫**（同侧额纹消失、眼睑闭合不全、口角歪斜——面神经核及以下损伤）vs **中枢性面瘫**（额纹存在、眼睑闭合正常——对侧皮质/脑干上运动神经元病变，提示脑血管病）。
- **鼻翼扇动**提示**呼吸困难**；**鼻出血**见于局部损伤、高血压、血液病；**鼻窦区压痛**提示**鼻窦炎**（额窦、上颌窦）。
- **舌**：**伸舌偏斜**提示**舌下神经损伤**；**舌震颤**见于**甲亢**；**舌质淡/暗、舌苔厚腻**可作为中医/一般状态的参考，但诊断学重点是**舌的运动、色泽、有无溃疡（口腔溃疡）、舌体肿胀（血管神经性水肿）**。
- **咽部充血、扁桃体肿大**提示**咽炎/扁桃体炎**；**扁桃体肿大分级**：I 度（不超过咽腭弓）、II 度（超过咽腭弓）、III 度（接近或达咽后壁中线）。**腮腺肿大**见于**流行性腮腺炎**、腮腺肿瘤。**口腔气味**（烂苹果、氨味、肝臭味）提示相应的代谢/肝肾功能异常。

**实际例子**：患者晨起发现一侧口角歪斜、鼻唇沟变浅、同侧额纹消失、眼睛闭合不全——**周围性面神经麻痹**；若仅口角歪斜而**额纹、眼睑闭合正常**，应考虑**中枢性面瘫（脑血管病）**。

### 头部检查要点对比表（面容与瞳孔异常）

| 体征 | 提示 |
|---|---|
| 方颅 | 佝偻病、先天性梅毒 |
| 巨颅 | 脑积水 |
| 双侧瞳孔缩小（针尖样） | 有机磷中毒、镇静催眠药、脑桥出血 |
| 双侧瞳孔散大 | 阿托品、氰化物、濒死 |
| 一侧瞳孔散大固定、对光反射消失 | 脑疝、严重颅内病变（急症） |
| 眼球突出（双侧） | 甲状腺功能亢进 |
| 巩膜黄染 | 黄疸 |
| 面神经麻痹：周围性 vs 中枢性 | 周围性额纹消失；中枢性额纹存在（脑血管病） |

## 第二节 颈部检查

**原理**：颈部检查包括**颈部姿势与运动、颈皮肤与包块、颈静脉、颈动脉、甲状腺、气管位置、颈部淋巴结**。颈部血管与甲状腺、气管位置是判断**循环系统**（右心衰、上腔静脉压迫）、**内分泌**（甲状腺）与**纵隔/胸腔病变**的重要依据。

**影响因素**：体位（取坐位或仰卧）、检查手法（视、触、听）、患者配合（做吞咽动作、屏气、转动颈部）、患者肥胖与颈部粗短、器械（叩诊锤、听诊器）。

### 一、颈部姿势、运动与皮肤包块

**原理**：观察颈部有无**强直（颈强直）、斜颈、运动受限、皮肤异常与包块**。颈强直是**脑膜刺激征**的重要组成，提示颅内感染或出血。

**影响因素**：颈部肌肉与颈椎病变、颅内或感染性病变、局部红肿、外伤。

**反向思考**：**颈强直、Kernig 征（克氏征）、Brudzinski 征（布鲁津斯基征）**共同构成**脑膜刺激征**，见于**脑膜炎、蛛网膜下腔出血**、颅内压增高——伴有头痛、发热、呕吐时应高度警惕。**颈部包块**需鉴别**甲状腺肿大、淋巴结肿大、囊肿、脂肪瘤、恶性肿瘤转移**；**斜颈**提示胸锁乳突肌痉挛或病变。

**实际例子**：患者高热、剧烈头痛、呕吐，查**颈强直**、克氏征阳性——**脑膜刺激征（提示脑膜炎/蛛网膜下腔出血）**。

### 二、颈静脉与颈动脉

**原理**：观察**颈静脉搏动与充盈**（颈静脉压）、**颈动脉搏动**及听诊有无**血管杂音**。颈静脉怒张反映**右心/上腔静脉回流受阻**。

**影响因素**：体位（半坐位、仰卧时的充盈度）、患者屏气（Valsalva 动作）、颈静脉压（正常平卧或 45° 半坐位时颈外静脉不明显充盈）。

**反向思考**：
- **颈静脉怒张**（颈静脉压升高、可见明显充盈或搏动）提示**右心衰竭、心包疾病（心包积液、缩窄性心包炎）、上腔静脉综合征、肺心病、大量胸腔积液**。
- **颈动脉搏动明显、洪大**见于**主动脉瓣关闭不全、高血压、甲状腺功能亢进**；颈动脉或锁骨下动脉杂音提示**动脉狭窄**（血管杂音）。
- **肝颈静脉回流征阳性**（按压右上腹时颈静脉搏动/充盈更明显）提示**右心衰竭**。

**实际例子**：颈静脉怒张、肝大、双下肢水肿、端坐呼吸、肝颈静脉回流征阳性——**右心衰竭**。

### 三、甲状腺

**原理**：甲状腺位于颈前，随**吞咽动作**上下移动。检查用**视诊**（肿大、对称、结节）、**触诊**（质地、大小、对称、结节、压痛、**震颤**——甲亢可触及震颤）、**听诊**（**血管杂音**）。肿大程度分级：**Ⅰ度**（不超过胸锁乳突肌内缘）、**Ⅱ度**（超过胸锁乳突肌内缘）、**Ⅲ度**（超过前正中线，或巨大）。

**影响因素**：患者吞咽配合（可让患者含水/做吞咽）、检查者用手轻推气管对侧、患者颈部充分放松与暴露、肥胖与颈粗。

**反向思考**：
- **甲状腺肿大**要区分**单纯性（地方性）甲状腺肿**（质软、无杂音、无甲状腺功能异常）、**甲状腺功能亢进（毒性弥漫性甲状腺肿）**（弥漫性肿大＋**震颤**＋**血管杂音**＋甲亢表现——怕热、多汗、心悸、眼球突出）、**甲状腺癌**（**单侧质硬、固定、无痛结节、可伴淋巴结转移**）、**桥本甲状腺炎**（质地较硬、无明显杂音）等。
- **质硬、固定、无痛、增长快**的甲状腺结节高度提示**甲状腺癌**；**有压痛**提示**甲状腺炎（亚急性、桥本）**；**甲状腺肿大伴血管杂音与震颤**是**甲亢**的重要特征。
- 检查时要在**吞咽时**触摸以确认是否随吞咽移动，并分别触诊**左右叶、峡部**；避免将肿大的淋巴结或胸骨后/舌下甲状腺误判。

**实际例子**：青年女性，颈前弥漫性肿大、随吞咽移动，触诊可及**震颤**，听诊有**甲状腺血管杂音**，伴怕热、多汗、心悸、手抖、突眼，T3/T4 升高、TSH 降低——**甲状腺功能亢进（Graves 病）**。

### 四、气管位置

**原理**：检查**气管是否居中**。正常气管位于颈前正中。用手指触诊**胸骨上切迹**处，判断气管有无偏斜（左右）。气管偏斜提示**胸腔/纵隔/肺**病变。

**影响因素**：体位、患者颈部肌肉、肥胖、局部包块、纵隔与胸腔病变。

**反向思考**：
- **气管向患侧移位**：见于**肺不张**（肺萎缩牵拉）、**肺硬化、肺纤维化**。
- **气管向健侧移位**：见于**大量胸腔积液、气胸**（占位把气管推向对侧）、巨大胸膜肿瘤。
- 气管旁有无**包块**也要结合甲状腺、纵隔淋巴结肿大判断。

**实际例子**：大量右侧胸腔积液患者，气管向左侧（健侧）移位，右侧叩诊实音、呼吸音减低——**气管向健侧移位**提示患侧占位（积液/气胸）。

### 颈部检查要点对比表

| 体征 | 提示 |
|---|---|
| 颈强直、克氏征（+）、布鲁津斯基征（+） | 脑膜刺激征（脑膜炎、蛛网膜下腔出血、颅内高压） |
| 颈静脉怒张、肝颈静脉回流征（+） | 右心衰竭、心包积液、上腔静脉综合征 |
| 颈动脉搏动明显、洪大 | 主动脉瓣关闭不全、高血压、甲亢 |
| 甲状腺弥漫性肿大＋震颤＋血管杂音 | 甲状腺功能亢进 |
| 甲状腺单侧质硬固定无痛结节 | 甲状腺癌 |
| 甲状腺肿大伴压痛 | 甲状腺炎 |
| 气管向患侧移位 | 肺不张、肺硬化 |
| 气管向健侧移位 | 大量胸腔积液、气胸 |

## 反向思考·临床思维自测（本章核心）

1. 一侧瞳孔散大固定、对光反射消失提示什么？（→ 脑疝、严重颅内病变（脑卒中、颅脑外伤），危重急症）
2. 双侧瞳孔针尖样缩小见于哪些情况？（→ 有机磷中毒、镇静催眠药中毒、脑桥出血）
3. 如何区分周围性面瘫与中枢性面瘫？（→ 周围性：同侧额纹消失、眼睑闭合不全；中枢性：额纹存在、眼睑闭合正常（脑血管病））
4. 颈强直、克氏征、布鲁津斯基征共同提示什么？（→ 脑膜刺激征（脑膜炎、蛛网膜下腔出血、颅内高压））
5. 颈静脉怒张、肝颈静脉回流征阳性提示什么？（→ 右心衰竭、心包积液、上腔静脉综合征）
6. 甲状腺肿大分几度？哪些体征提示甲亢？（→ Ⅰ～Ⅲ度；弥漫性肿大＋震颤＋血管杂音＋甲亢表现（怕热、心悸、突眼））
7. 质硬、固定、无痛、增长快的甲状腺结节提示什么？（→ 甲状腺癌）
8. 气管向患侧移位 vs 向健侧移位的常见原因？（→ 向患侧：肺不张/肺硬化；向健侧：大量胸腔积液、气胸）

> 记忆口诀：**头颈细看多信息——眼球震突瞳不等（散大固定防脑疝），巩膜黄染眼睑肿；口角偏斜分中枢（额纹在对侧正常）与周围（额纹消失眼难闭）；颈强直克氏枕脑膜，颈静脉怒张右心败，甲状腺随吞动，震颤杂音是甲亢，硬固定痛防癌变；气管移位胸疾辨。**

## 临床实例小结

- **脑疝/急性脑卒中**：一侧瞳孔散大固定、对光反射消失、意识障碍，需急诊处理。
- **脑膜炎（脑膜刺激征）**：颈强直、克氏征阳性、高热、头痛、呕吐。
- **周围性面瘫**：同侧额纹消失、眼睑闭合不全、口角歪斜（面神经损伤）。
- **中枢性面瘫（脑梗死）**：仅口角歪斜、鼻唇沟变浅，额纹存在、眼睑闭合正常。
- **甲状腺功能亢进（Graves 病）**：颈前弥漫性肿大、震颤、血管杂音，伴怕热多汗、心悸、突眼。
- **甲状腺癌**：单侧质硬、固定、无痛结节，增长快，可伴颈部淋巴结转移。
- **右心衰竭**：颈静脉怒张、肝颈静脉回流征阳性、肝大、双下肢水肿。
- **大量胸腔积液**：气管向健侧移位、患侧叩诊实音、呼吸音减低。
