## 呕血的定义与发生机制

**原理**：**呕血**指**上消化道（食管、胃、十二指肠）大量出血**，血液经口呕出。多为**呕出的血液为暗红/咖啡色**（胃酸作用使血红蛋白分解为正铁血红素）。呕血常提示**上消化道大出血**，可伴**黑便（柏油样便）**、失血性休克、血容量不足等症状。发生机制包括**消化性溃疡侵蚀血管、食管-胃底静脉曲张破裂（门静脉高压）、急性胃黏膜病变（应激/药物 NSAIDs）、胃癌溃烂、食管贲门黏膜撕裂（Mallory-Weiss 综合征）、胆道出血、食管炎**等。

**影响因素**：出血来源（食管、胃、十二指肠、胆胰）、出血量与速度（量大速度快→呕血为主+失血性休克；量小或缓慢→黑便为主）、病变性质（溃疡、血管、肿瘤、黏膜病变）、凝血功能、诱因（饮酒、NSAIDs/阿司匹林、应激、肝硬化门脉高压、剧烈呕吐、抗凝药）、患者基础病与年龄。

**反向思考**：
- **呕血颜色变化**：**鲜红色**提示出血量大、位置高（食管）或出血速度快（未及胃酸作用）；**咖啡色（暗红）**提示出血在胃内停留、经胃酸作用——**颜色反映出血量与停留时间**。
- **呕血 vs 咯血**：来源、颜色、pH、混杂物、伴随症状不同（见对比表）——**口吐鲜血不一定是呕血，也可能咯血**，要查清来源。
- **"上消化道出血"以黑便为主而呕血轻**：**幽门以下出血**（十二指肠）或出血量较小、速度慢时，血液在肠道停留久即为黑便——**出血部位越靠下、速度越慢，越以黑便为主**；反之呕血明显。
- **呕血伴肝病体征（肝掌蜘蛛痣、腹水、黄疸、脾大）** → **肝硬化食管-胃底静脉曲张破裂**（占上消化道大出血的大比例），是急重症，需紧急降低门脉压（生长抑素、内镜套扎/硬化）。
- **呕血"消失"后的再出血**：出血暂停后再呕血提示**活动性出血**，需紧急内镜判断出血源与止血。
- **大便颜色与出血量**：出血量达 **50~100 ml** 即可出现**黑便**；达 **250~300 ml** 可致呕血；急性出血量大可出现**失血性休克**（头晕、心慌、苍白、大汗、血压下降、脉细速）——**先评估血容量与意识，再处理出血源**。

**实际例子**：肝硬化患者**大量呕鲜血、伴脾大、腹水、肝掌蜘蛛痣**，发病前饮酒/食硬物 → **食管-胃底静脉曲张破裂出血**；中年女性**长期服用阿司匹林/NSAID 后呕咖啡色物、黑便** → **急性胃黏膜病变 / 消化性溃疡出血**。

## 呕血/上消化道出血的病因与分类

**原理**：按病因分类：① **消化性溃疡（胃、十二指肠溃疡）**——最常见原因；② **食管-胃底静脉曲张破裂**（肝硬化门静脉高压）；③ **急性胃黏膜病变**（应激、NSAIDs/阿司匹林、酒精、急性胃炎）；④ **胃癌**（肿瘤溃烂出血）；⑤ **食管贲门黏膜撕裂（Mallory-Weiss 综合征）**（剧烈呕吐后撕裂）；⑥ **其他**：食管炎、食管癌、胆道出血、血液病、凝血障碍、尿毒症。

**影响因素**：病因（溃疡、曲张静脉、胃黏膜病变、肿瘤、黏膜撕裂、凝血障碍）、出血量与速度、诱因（饮酒、NSAIDs、应激、肝硬化失代偿、剧烈呕吐、抗凝药、肝肾功能）、患者年龄、凝血状态、基础病（慢性肝病、肾衰、血液病）。

**反向思考**：
- **"腹痛—呕血—黑便"三联征**常为**消化性溃疡**；**"无痛性上消化道大出血**（时隐时现、以黑便为主）要考虑**胃癌、食管-胃底静脉曲张、血友病等**——**无痛性出血别忽略肿瘤与凝血/血液病**。
- **剧烈干呕后呕血** → **Mallory-Weiss 综合征**（食管贲门黏膜纵形撕裂）——好发于饮酒、妊娠呕吐、剧烈咳嗽之后，与溃疡出血机制不同。
- **上消化道出血的"血尿素氮升高、肌酐正常"**（肠道血吸收→氮质血症）是辅助线索，但应结合氮质血症来源不特异性。
- **年龄大、出血量大、黑便次数多、伴晕厥/休克**提示**高危出血**，需评估血流动力学、监测血红蛋白、尽早内镜止血；**高龄+无痛性出血 + 贫血 + 消瘦**警惕胃癌。
- **呕血伴黄疸、腹水、肝掌、蜘蛛痣**高度提示**肝硬化门脉高压性出血**，与溃疡出血的病因、治疗（降门脉压+内镜 vs 抑酸+内镜）不同——**病史与体征的分流至关重要**。

**实际例子**：青年男性**反复上腹痛、饥饿性痛、进食缓解、突发黑便** → **十二指肠溃疡出血**；一位长期饮酒者**剧烈干呕后呕鲜血** → **食管贲门黏膜撕裂（Mallory-Weiss）**。

## 便血的定义与发生机制

**原理**：**便血**指**血液自肛门排出**，多提示**下消化道（回肠末端、结肠、直肠、肛门）出血**，也可由**上消化道出血量较大、速度快**时随粪便排出（此时常为**黑便/柏油样便**，血在肠道停留久）。**黑便（柏油样便）**由**血红蛋白 + 胃酸/肠道硫化物生成硫化铁**而成，提示**上消化道或小肠高位出血**；**鲜血便/暗红血便**多提示**低位（结肠、直肠、肛门）出血**。发生机制包括**炎症（溃疡性结肠炎）、肿瘤（结肠癌、直肠癌）、息肉、痔、肛裂、肠套叠、缺血性结肠炎、肠道血管畸形、感染性肠炎、菌痢**等。

**影响因素**：出血部位（上 vs 下、高位 vs 低位）、出血量与出血速度、血液在肠道停留时间、大便性状与颜色、病因（炎症、癌、息肉、痔、肛裂、血管畸形、感染）、伴随症状（腹痛、腹泻、里急后重、消瘦、大便性状改变）、年龄。

**反向思考**：
- **大便颜色判断出血部位**：**柏油样黑便**（黏稠、油亮）——**上消化道或高位小肠**出血；**暗红色血便**——**低位小肠/结肠**；**鲜红色血便**（附着于大便表面或手纸）——**直肠、肛门（痔、肛裂）**出血；**大便带鲜血于表面、排便后出血** → 肛门直肠（痔、肛裂）为主——**颜色越鲜红，部位越低**。
- **鲜血便 ≠ 一定是痔**：**便血+持续大便习惯改变（腹泻便秘交替、大便变细）+消瘦+贫血** → **结直肠癌**（报警症状）；**便血+黏液脓血便+里急后重+腹痛** → **溃疡性结肠炎/感染性结肠炎/菌痢**——**"痔出血"是常见误诊**，中老年出现便血必先排除肠癌。
- **黑便 vs 便血的颜色造假因素**：**咽下血液（鼻衄、咯血咽下）、服用铁剂、铋剂、动物血、复方中药**可致**假性黑便**；但**便隐血试纸 + 化验血色素**可鉴别。**假性黑便要排除**（问饮食药物），否则误判为消化道出血。
- **黑便可提示上消化道出血达 50~100 ml**；**仅隐血阳性（便隐血）**提示小量出血，需排查肿瘤性病变（结直肠癌筛查）。
- **腹痛+便血**：**肠套叠（儿童阵发性腹痛+果酱样便）、缺血性结肠炎（老人腹痛后便血）、溃疡性结肠炎（黏液脓血便+腹痛）、细菌性痢疾（发热+里急后重+黏液脓血便）**——伴随腹痛与发热性质决定病因。

**实际例子**：儿童**阵发性哭闹、腹痛、腹部腊肠样包块 + 果酱样血便** → **肠套叠**；中老年**便血+贫血+消瘦+大便变细、大便习惯改变** → **结直肠癌**（需肠镜）。

### 上消化道出血 vs 下消化道出血对比表

| 鉴别点 | 上消化道出血 | 下消化道出血 |
|---|---|---|
| 出血来源 | 食管、胃、十二指肠（+胆胰） | 回肠末端、结肠、直肠、肛门 |
| 常见病因 | 消化性溃疡、食管-胃底静脉曲张、急性胃黏膜病变、胃癌、Mallory-Weiss | 结直肠癌、息肉、溃疡性结肠炎、痔、肛裂、肠套叠、缺血性肠病 |
| 粪便颜色 | 柏油样黑便（高位慢速）或呕血 | 暗红/鲜红血便（低位） |
| 主要表现 | 呕血+黑便、可伴休克 | 便血（鲜血/暗红）、里急后重、腹痛 |
| 胃酸作用 | 血液经胃酸→咖啡色/黑便 | 血液未经充分胃酸作用→鲜红/暗红 |
| 伴随症状 | 上腹痛、肝硬化体征、晕厥 | 腹痛、腹泻、里急后重、消瘦、大便性状改变 |
| 首选检查 | 急诊胃镜 | 肠镜 |

## 便血的病因与伴随症状/问诊要点

**原理**：便血可由**炎症性**（溃疡性结肠炎、克罗恩病、感染性肠炎、菌痢）、**肿瘤性**（结直肠癌、息肉）、**血管性**（缺血性结肠炎、血管畸形）、**肛门直肠**（痔、肛裂、肛瘘）、**其他**（肠套叠、血液病、凝血障碍）引起；问诊重点是**便血颜色与量、出血与排便关系（粘附/滴血）、有无伴随腹痛腹泻里急后重、粪便性状改变、发热、消瘦、贫血、用药史（NSAIDs、抗凝）、家族史（结直肠癌、息肉）**。

**影响因素**：病因、出血部位、出血量与速度、伴发症状（腹痛、腹泻、里急后重、发热、消瘦、贫血）、粪便性状与颜色、年龄（儿童/青年/老年病种不同：儿童肠套叠、幼年息肉；青年溃疡性结肠炎、痔；老年结直肠癌）、用药与基础病（抗凝、NSAIDs、肝硬化凝血障碍）。

**反向思考**：
- **便血 + 腹泻 + 发热 + 里急后重** → **溃疡性结肠炎或感染性肠炎/菌痢**；**便血 + 腹痛阵发性 + 呕吐 + 停止排气排便** → **肠梗阻/肠套叠/肠扭转**（急腹症）；**便血 + 突发剧烈腹痛 + 老人** → **缺血性结肠炎/肠系膜血管栓塞**——急症优先。
- **便血 + 消瘦 + 贫血 + 大便习惯改变** → **结直肠癌**（必须肠镜检查，勿"想当然"当痔归咎）。
- **便血 + 全身出血倾向（皮肤瘀斑、鼻衄、牙龈出血）** → **血小板/凝血病（血友病、白血病、DIC）、抗凝药过量**——不能只看肠道。
- **便血 + 肝硬化体征**（脾大、腹水、肝掌） → **门静脉高压性肛门直肠静脉曲张/痔 + 凝血功能障碍复合出血**。
- 问诊要鉴别**"黑便"是否为假性**（铁剂/铋剂/动物血/中草药、咽血）；**便隐血阳性**需结合**结直肠癌筛查**（±肠镜）明确，不能一年复查了事。

**实际例子**：中年女性**反复便鲜血、手纸带血、便秘加重**，误以为痔疮，半年后**贫血、消瘦**，肠镜示**直肠癌**；老年患者**有“三高”、突发腹痛后暗红血便** → **缺血性结肠炎**——提示"便血不都是痔/肠炎"。

## 反向思考·自测题（本章核心）

1. 呕血颜色从鲜红到咖啡色说明什么？（→ 出血量大、位置高、速度快→鲜红未及胃酸；咖啡色为胃内停留久、经胃酸）
2. 黑便提示出血量约为多少？什么情况下以黑便为主？（→ ≥50~100 ml；出血部位靠下（十二指肠以下）或速度慢）
3. 上消化道出血常见的四大病因？（→ 消化性溃疡、食管-胃底静脉曲张、急性胃黏膜病变、胃癌；勿忘 Mallory-Weiss 撕裂）
4. 为什么"无痛性上消化道出血"要想到胃癌、血液病、静脉曲张？（→ 无痛性出血常为肿瘤或凝血障碍/静脉曲张等，需进一步排查）
5. 大便颜色如何提示出血部位？（→ 柏油黑便→上消化道/高位小肠；暗红→低位小肠/结肠；鲜红→直肠/肛门；颜色越鲜红部位越低）
6. 为什么便血不一定是痔？（→ 可与结直肠癌、溃疡性结肠炎、缺血性肠病、肠套叠等混淆，中老年便血必须排除肠癌）
7. 何种"假性黑便"会被误判为消化道出血？（→ 铁剂、铋剂、动物血、含动物血的中药、咽下鼻衄咯血）
8. 便血+阵发性腹痛、呕吐、停止排气排便是哪些急症？（→ 肠套叠、肠扭转、肠梗阻、肠系膜血管栓塞等急腹症，需急诊处理）

> 记忆口诀：**呕血便血四段辨，咖啡黑色是上消，鲜红暗红是下消，柏油黑便位置高，颜色越鲜越靠肛；消化溃疡最常见，曲张静脉肝硬变，胃黏膜病变与胃癌，剧烈呕吐撕裂样（Mallory-Weiss）；便血别当痔，便习改+瘦+贫血先查肠癌，假黑便想铁铋血，出血先保命再查源。**
