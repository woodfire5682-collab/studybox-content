## 咳嗽与咳痰的定义与发生机制

**原理**：咳嗽是一种**保护性反射动作**，由分布在呼吸道黏膜的**咳嗽反射弧**完成（感受器→传入[迷走、舌咽、三叉神经]→延髓咳嗽中枢→传出[迷走、膈神经、脊神经]→效应器）。其作用是清除呼吸道异物与分泌物。**咳痰**是呼吸道黏膜的**分泌物（黏液、浆液、细胞、病原体、坏死物）**经咳嗽排出。痰的生成与**杯状细胞、黏液腺分泌**密切相关。

**影响因素**：刺激源（炎症、异物、理化刺激、冷空气、过敏原）、反射弧完整性、黏液分泌量与黏稠度、纤毛运动功能、体位、患者意识状态（咳嗽反射受抑制）。

**反向思考**：
- 咳嗽的本质是**防御**而非疾病本身——**止咳不是唯一目的**，一味镇咳反而让痰液滞留、感染迁延（痰多者应先祛痰再考虑镇咳）。
- **咳嗽反射受抑制者（老人、昏迷、喉返神经麻痹）可能"咳不出来"**——痰液误吸导致吸入性肺炎，是"无咳嗽"的敌人。
- **干咳 vs 咳痰**：**干咳**多提示**刺激性与非感染性**（上气道咳嗽综合征、咳嗽变异性哮喘、胃食管反流性咳嗽、ACEI 类药物、心因性）；**咳痰**多提示**感染与分泌性**（支气管炎、肺炎、支扩、肺脓肿）。

**实际例子**：服用**卡托普利（ACEI）**后出现顽固**干咳**，停药后缓解——**药源性干咳**；支气管扩张患者每日大量**脓痰**、晨起或体位改变时痰多——痰量与体位关系的典型。

## 咳嗽的分类与临床特点

**原理**：按病程分为**急性**（＜3 周）、**亚急性**（3~8 周）、**慢性**（＞8 周）；按有无痰分为**干咳**与**湿咳（有痰）**；按时相分为**晨咳**、**夜咳**、**体位性咳嗽**等。不同分类对应不同病因。

**影响因素**：病程与病因（急性：上感、支气管炎、肺炎；慢性：COPD、哮喘、结核、支扩、肺癌、胃食管反流、ACEI 药物）、时相（晨咳与体位、夜咳哮喘）、痰的性状与量、伴随症状、职业与环境暴露。

**反向思考**：
- **慢性咳嗽**切忌一律按"支气管炎"用抗生素——**咳嗽变异性哮喘、上气道咳嗽综合征、胃食管反流性咳嗽、嗜酸粒细胞性支气管炎、ACEI 药物**是慢性咳嗽五大常见原因，抗生素无效是重要提示。
- **咳嗽变异性哮喘（CVA）**：以**夜间刺激性干咳**为主、无喘息哮鸣音，极易误诊为慢性咽炎/支气管炎——**支气管激发试验**是鉴别关键。
- **晨咳 + 大量脓痰**提示**慢性支气管炎、支气管扩张**；**夜间阵发性咳嗽伴呼吸困难**提示**左心衰**——时相与症状结合定位。
- **咳嗽 + 痰中带血或胸痛 + 年龄大 + 吸烟** → 警惕**肺癌**，不可当"感冒/支气管炎"草草按胸部 X 线即否定。

**实际例子**：老人长期**晨起咳痰、有 40 年烟龄、近期痰中带血、消瘦** → 胸片示肺门肿块 → **肺癌**；而咳嗽变异性哮喘患者夜间干咳数月、抗生素无效、支气管激发试验阳性 → **吸入激素**治疗有效。

## 痰的性状与颜色（痰液特征的意义）

**原理**：痰的**性状、颜色、量、气味**直接反映气道与肺部的病理改变，是定位病变性质的重要线索。痰量（少量/大量）、性状（浆液性、黏液性、黏液脓性、脓性、血性、泡沫状）、颜色（白、黄、绿、铁锈色、粉红色、烂桃样、恶臭）。

**影响因素**：病原体与炎症类型、组织坏死程度、出血、急性/慢性、病理产物（坏死组织、纤维素、寄生虫等）。

**反向思考**：
- **铁锈色痰** = 大叶性肺炎（肺炎链球菌）；**粉红色泡沫状痰** = 肺水肿（左心衰）；**砖红色胶冻状痰** = 克雷伯杆菌肺炎；**大量脓臭痰（分层）** = 肺脓肿/支气管扩张；**烂桃样痰** = 肺吸虫——痰的颜色是"病原体名片"。
- **大量脓痰且分层（上层泡沫、中层黏液、下层脓渣）** → 支气管扩张或肺脓肿；脓痰量**突然减少但全身中毒加重** → 警惕**支气管阻塞（脓痰引流不畅）**。
- **恶臭痰**提示**厌氧菌感染**（肺脓肿、支气管扩张继发厌氧菌）；**黏液性痰**可见于哮喘、慢支——"看痰"有时比"等培养"更快指向病原。

**实际例子**：护理中观察到患者咳**粉红色泡沫状痰** + 端坐呼吸、双肺底湿啰音 → **急性左心衰肺水肿**，需强心利尿扩血管，而非抗感染。

## 咯血的定义与发生机制

**原理**：**咯血**指喉以下呼吸道（气管、支气管、肺组织）出血经咳嗽从口腔排出。出血来源可为**支气管动脉**（压力高，出血量大）或**肺循环/肺毛细血管**（压力低，出血量相对小）。多因**病变损伤血管壁、炎性侵蚀、肿瘤坏死、血管异常、凝血障碍**等所致。需与**呕血**严格鉴别。

**影响因素**：病因（支气管扩张、肺结核、支气管肺癌、肺炎、肺脓肿、二尖瓣狭窄、肺梗死、肾炎肺出血综合征、血液病）、出血量、部位、血管类型、凝血功能。

**反向思考**：
- **咯血 vs 呕血**是首要鉴别——病史、颜色、酸碱度（pH）、混杂物都对**（见对比表）**：咯血是**痰中带血、鲜红、泡沫状、碱性、pH＞7、与相伴随咳嗽泡沫痰**；呕血是**暗红或咖啡色、酸性、混有食物残渣、黑便、伴恶心**。误把呕血当咯血（或反之）会走错方向。
- **咯血量**分级：**痰中带血** → **小量咯血**（＜100 ml/24h） → **中量**（100~500 ml） → **大量**（＞500 ml 或一次 100 ml 以上）。**大咯血**可致**窒息与失血性休克**，是急症。
- **青壮年反复咯血 + 慢性咳嗽咳脓痰** → **支气管扩张**；**40 岁以上吸烟者咯血 + 消瘦** → **肺癌**；**低热盗汗午后潮热 + 咯血** → **肺结核**——年龄与伴随症状帮助定位。
- **大咯血突发窒息**（胸闷、呼吸困难、面色青紫、烦躁）比出血本身更致命——处理大咯血要防窒息优先于止血。

**实际例子**：患者**粉红色泡沫痰 + 痰中带血 + 端坐呼吸** → 二尖瓣狭窄/左心衰性咯血；而**大量鲜红血伴剧烈咳嗽、逐渐出现窒息** → 支气管扩张大咯血，需紧急吸引保持气道通畅。

### 咯血与呕血对比表

| 鉴别点 | 咯血 | 呕血 |
|---|---|---|
| 来源 | 喉以下呼吸道、肺 | 上消化道（食管、胃、十二指肠） |
| 前驱症状 | 咳嗽、胸闷、喉部痒感 | 恶心、上腹不适、呕吐 |
| 颜色与性状 | 鲜红、泡沫状、混有痰液 | 暗红或咖啡色、混有食物残渣 |
| 酸碱度（pH） | 碱性（pH＞7） | 酸性（pH＜7） |
| 排出方式 | 随咳嗽排出（血丝痰/泡沫样） | 呕吐排出 |
| 粪便 | 无（除非咽下） | 可伴黑便 |
| 基础疾病 | 支气管扩张、肺结核、肺癌、心衰 | 溃疡、食管静脉曲张、胃癌 |

## 咯血的病因与诊断鉴别

**原理**：咯血病因分**感染性**（支气管扩张、肺结核、肺炎、肺脓肿、肺真菌病）与**非感染性**（支气管肺癌、二尖瓣狭窄、肺梗死、肺动-静脉畸形、血液病、胶原病如肺出血-肾炎综合征）。

**影响因素**：年龄、性别、吸烟史、基础病（心脏病、血液病）、流行病学史（结核接触）、伴随症状（发热、胸痛、消瘦、盗汗）、部位与血管来源。

**反向思考**：
- **肺部病变以中上肺、痰检抗酸阳性**提示肺结核；**以咳嗽、咳大量脓痰、反复咯血为主**提示支气管扩张；**以吸烟男性、胸痛、消瘦、痰血、胸片肿块**提示肺癌——三大病因要用"年龄+吸烟+症状+影像"区分。
- **"咯血伴呼吸困难、胸痛、发绀"** 要想到**肺梗死**（栓子来源：下肢静脉、房颤、术后长期卧床）——与肺炎鉴别，需 D-二聚体、增强 CT 肺血管造影。
- **大咯血突然停止并发窒息**时不能只盯住"出血量"，要评估**气道是否堵塞**；**咯血伴一侧呼吸音减弱、叩浊** → **血阻塞患侧肺**，要尽快清路。
- 咳痰与咯血并存但**咯血量少、以痰中带血为主**时，勿忽视**肺部细小肿瘤或早期结核**，建议 CT 而非仅胸片。

**实际例子**：40 岁男性吸烟、夜间**痰中带血**、胸片发现**右上肺结节伴分叶毛刺** → **早期肺癌**；青年女性反复低热盗汗、**咯血、痰涂片抗酸杆菌阳性** → **肺结核**。

## 咳嗽/咳痰/咯血的问诊要点

**原理**：问诊聚焦**咳嗽的病程、时相、性质、痰量与性状、伴随症状，咯血的出血量、来源、颜色、诱因**，并询问**吸烟史、职业暴露、结核接触、心肺基础病、用药史（ACEI）**。

**影响因素**：患者叙述准确性、病程与诱因、痰与血的特征、伴随症状、既往史（哮喘、COPD、胃食管反流、心脏病、结核）、吸烟与职业史。

**反向思考**：
- **"咳嗽首发时段"能定位**：晨咳（慢支、支扩）、夜间咳嗽（CVA、左心衰、胃食管反流）、进食后咳嗽（胃食管反流、食管裂孔疝）、运动后咳嗽（哮喘）。
- **用药史**（尤其 **ACEI** 类降压药）必须问——药源性干咳占慢性咳嗽重要比例，病史明确即可停药观察，不必反复检查。
- **痰性状与量**要精确询问（泡沫状？铁锈色？脓臭分层？每天多少口/毫升）——它为病原与病种提供直接线索。
- 咯血问诊要**排除伪咯血（鼻咽部出血）**，并询问**是否吞入后出现黑便**，必要时鉴别上呼吸道来源。

**实际例子**：一名患者"反复咳嗽、痰少、夜间明显"，接受多种抗生素无效，追问发现正在服**依那普利** → 改药后咳嗽消失——**ACEI 诱发咳嗽**，问清用药史即确诊。

## 反向思考·自测题（本章核心）

1. 铁锈色痰、粉红色泡沫状痰、砖红色胶冻状痰、烂桃样痰各见于什么病？（→ 大叶性肺炎、左心衰肺水肿、克雷伯杆菌肺炎、肺吸虫）
2. 咯血与呕血如何快速鉴别？（→ 颜色、pH、混杂物、前驱症状、是否黑便——鲜红泡沫碱性与暗红咖啡酸性）
3. 为什么慢性咳嗽不能一律按支气管炎用抗生素？（→ 慢性咳嗽五大病因中 CVA、上气道咳嗽综合征、GERD、嗜酸粒细胞性支气管炎、ACEI 均非细菌感染，抗生素无效）
4. 大咯血最危险的并发症是什么？处理时优先考虑什么？（→ 窒息与大出血性休克；首要保持气道通畅防窒息）
5. 40 岁以上吸烟者痰中带血应警惕什么？（→ 肺癌，需进一步 CT 检查）
6. 痰量突然减少但全身中毒症状加重说明什么？（→ 支气管阻塞致脓痰引流不畅，需解除阻塞）
7. 为什么用药史（尤其 ACEI）对慢性咳嗽问诊至关重要？（→ 药源性干咳是常见可逆原因，停药即可，避免滥用抗生素）
8. 咳嗽变异性哮喘为何易误诊、如何确诊？（→ 以夜间干咳为主无喘息，常误诊为咽炎/支气管炎；支气管激发试验阳性可确诊）

> 记忆口诀：**咳嗽防御莫强镇，痰多先祛痰再镇咳；慢性咳嗽五因查，CVA、咽炎、反流噫，ACEI 药干咳；铁锈大叶、粉红肺水肿，酱红克雷伯、烂桃吸虫；咯血呕血要分清，鲜红泡碱是咯血，暗红食残是呕血，大咯血防窒息。**
