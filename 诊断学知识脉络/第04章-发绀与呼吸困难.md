## 发绀的定义与发生机制

**原理**：**发绀**指血液中**还原血红蛋白增多或含有异常血红蛋白衍生物**（如高铁血红蛋白、硫化血红蛋白）时，皮肤黏膜呈现**青紫色**。发绀的程度取决于**还原血红蛋白的绝对量**而非比例——通常当**毛细血管血中还原血红蛋白 ≥ 50 g/L**（约 5 g/dL）时即出现发绀。常见部位为**口唇、鼻尖、颊部、甲床、耳廓**等末梢薄皮部位。

**影响因素**：还原血红蛋白绝对量、血红蛋白总量（贫血者易"不青紫"；红细胞增多症者易青紫）、皮肤色素与厚度、局部循环、光线、异常血红蛋白（高铁/硫化血红蛋白）。

**反向思考**：
- **发绀的判断要看"还原血红蛋白绝对量"而非百分比**——贫血患者即便氧饱和度明显降低，因还原血红蛋白总量不足也可能**不出现发绀**；反之红细胞增多症患者即使缺氧较轻也易青紫。**"越贫血越青紫"是错误的**，这是最常见的概念陷阱。
- **发绀 ≠ 缺氧**，**缺氧 ≠ 发绀**：二者可分离。严重贫血可缺氧但不发绀；一氧化碳中毒（形成碳氧血红蛋白，呈樱红色）重度缺氧却**无发绀**（皮肤呈樱桃红）；氰化物中毒抑制细胞呼吸，缺氧却不出现发绀。
- **发绀可见于无缺氧的血液异常**：高铁血红蛋白血症（如亚硝酸盐中毒）、硫化血红蛋白血症——这类发绀**吸氧无效**（吸氧不能还原异常血红蛋白），提示溶血性/中毒性发绀。

**实际例子**：一氧化碳中毒患者皮肤黏膜呈**樱桃红色**、意识障碍、SpO₂ 测量值看似正常（碳氧血红蛋白干扰）→ 严重缺氧却无发绀；亚硝酸盐中毒者进食不新鲜腌菜后口唇指甲青紫、吸氧无效 → 高铁血红蛋白血症。

## 发绀的病因与分类（中心性 vs 周围性）

**原理**：按发生机制分为**中心性发绀**与**周围性发绀**，二者机制与处理不同。
- **中心性发绀**：由**动脉血氧饱和度降低**所致（肺性[呼吸功能不全、肺水肿、肺栓塞]或心性[右向左分流的先天性心脏病]），发绀**全身性、对称、黏膜明显、伴呼吸困难与杆状指**。
- **周围性发绀**：由**末梢循环淤血或灌注不足**所致（肢体动脉缺血、右心衰、休克、寒冷、红细胞增多），发绀**以肢端、耳垂、鼻尖为著，局部皮肤凉、黏膜不受影响**。

**影响因素**：病因（心肺功能不全、右向左分流、循环障碍、休克、寒冷、血液黏滞、异常血红蛋白）、部位（中心性累及黏膜，周围性累及肢端）、气温、局部循环、血红蛋白与异常血红蛋白。

**反向思考**：
- **鉴别要点是"发绀部位 + 是否伴呼吸困难 + 局部温度"**：**中心性**的明显特征是**舌、唇、口腔黏膜也发绀**且常伴**杵状指和呼吸困难**；**周围性**以**肢端为主、皮肤凉、口唇黏膜可正常**——**看"舌与口唇黏膜"**是快速鉴别口诀。
- **右向左分流（法洛四联症）**的中心性发绀是**慢性、伴杵状指**，自幼存在；老年期突发 "发绀" 要想到肺栓塞、呼吸衰竭。
- **高铁血红蛋白血症**（亚硝酸盐、硝基苯、苯胺中毒）引起的发绀：**吸氧无效、血呈巧克力色、皮肤青紫而氧分压可能正常**——与真正缺氧性发绀区分需测**分光光度法**血氧。
- **成人呼吸窘迫/肺水肿**所致急性中心性发绀需紧急处理——误当周围性（用保暖、扩血管）会延误抢救。

**实际例子**：法洛四联症患儿自幼口唇发绀、蹲踞、杵状指、活动后气促 → **中心性发绀（右向左分流）**；冬季老年人手足发绀发凉、保暖后缓解、血气正常 → **周围性发绀（寒冷性末梢循环差）**。

### 中心性 vs 周围性发绀对比表

| 对比项 | 中心性发绀 | 周围性发绀 |
|---|---|---|
| 发生机制 | 动脉血氧饱和度降低 | 末梢循环淤血/灌注不足 |
| 发绀部位 | 全身皮肤+口腔黏膜、舌、唇 | 肢端、耳垂、鼻尖为主 |
| 皮肤温度 | 多温暖 | 多发凉 |
| 呼吸困难 | 常有 | 常无或轻 |
| 杵状指 | 常见（慢性） | 无 |
| 缓解方式 | 吸氧可改善（除异常血红蛋白） | 保暖、改善循环可缓解 |
| 典型病因 | 肺功能不全、右向左分流先心病 | 右心衰、休克、寒冷、红细胞增多 |
| 异常血红蛋白 | 高铁/硫化血红蛋白（吸氧无效） | 无 |

## 呼吸困难的定义与发生机制

**原理**：**呼吸困难**指患者主观上感到**空气不足、呼吸费力**，客观上表现为**呼吸频率、深度、节律的异常**，可伴鼻翼扇动、辅助呼吸肌参与、端坐呼吸。其发生与**呼吸系统负荷增加（通气/换气障碍）、循环系统（肺淤血）、代谢性（酸中毒）、神经精神性**等因素有关。可分**吸气性、呼气性、混合性**三种类型。

**影响因素**：气道阻塞部位（上气道→吸气性；下气道/小气道→呼气性）、肺实质与肺血管病变（混合性）、心功能（左心衰）、代谢（酸中毒）、贫血、神经肌肉、精神心理、体位与诱因。

**反向思考**：
- **吸气性 vs 呼气性呼吸困难**：**吸气性**（上气道狭窄，如喉水肿、喉炎、气管异物、肿瘤）表现为**三凹征**（胸骨上窝、锁骨上窝、肋间隙凹陷）与吸气性哮鸣音；**呼气性**（小气道/肺弹性下降，如哮喘、COPD）表现为**呼气费力、呼气延长、伴哮鸣音**——"吸凹呼哮"是有效口诀。
- **心源性（左心衰）呼吸困难**有特征性：**劳力性→夜间阵发性（夜间阵发性呼吸困难）→端坐呼吸**加重的演进；夜间惊醒、坐起缓解、伴粉红色泡沫痰与双肺底湿啰音——与支气管哮喘（呼气性哮鸣音、无泡沫痰）鉴别是经典考点，**"心源性哮喘 vs 支气管哮喘"**勿混淆。
- **代谢性酸中毒（如糖尿病酮症酸中毒、尿毒症）**表现为**深大而规律的呼吸（Kussmaul 呼吸）**，是代偿性深快——这种"呼吸深而快"别只当呼吸系统病。
- **呼吸节律异常**（潮式/Cheyne-Stokes 呼吸、间停/Biot 呼吸）提示**中枢性呼吸衰竭、颅内病变**——节律异常指向神经/中枢，而非单纯肺部。
- **精神心理性呼吸困难**（过度通气综合征）：年轻女性情绪激动后**呼吸深快、口周麻木、手足搐搦**，血气示**呼吸性碱中毒**——需与器质性呼吸困难区分，但必须先排除器质性。

**实际例子**：喉头水肿/声门异物患儿突发**吸气性三凹征 + 吸气性哮鸣音** → **吸气性呼吸困难**；支气管哮喘急性发作患者**呼气费力、呼气延长、满肺哮鸣音** → **呼气性呼吸困难**。

## 呼吸困难的病因与分类

**原理**：按病因分为：① **肺源性**（上气道阻塞、哮喘、COPD、肺炎、肺梗死、肺间质病、肺水肿）；② **心源性**（左心衰、右心衰、心包积液）；③ **中毒性**（酸中毒、CO、氰化物、药物中毒）；④ **血源性**（严重贫血、大出血、高铁血红蛋白）；⑤ **神经精神性**（中枢病变、过度通气、癔症）。

**影响因素**：病种、起病缓急（急性：异物、哮喘、心衰、肺栓塞；慢性：COPD、肺间质病、心衰）、诱因（劳力、平卧、激动、过敏）、伴随症状、年龄与基础病。

**反向思考**：
- **急性呼吸困难**先排除**危重症**：**急性左心衰肺水肿（粉红色泡沫痰）、肺栓塞（突发胸痛+呼吸困难）、气道异物、气胸、喉头水肿、哮喘持续状态、严重过敏（过敏性休克）**——处理顺序是"先救命，后找病因"。
- **肺栓塞**是"最容易漏诊的急症"：**突发呼吸困难+胸痛+咯血+单侧下肢肿（DVT）**三联征，需 D-二聚体与 CTPA，漏诊死亡率高。
- **心源性哮喘 vs 支气管哮喘**：**端坐呼吸、粉红色泡沫痰、双肺底湿啰音**偏心衰；**呼气性哮鸣音、痰少黏稠、既往哮喘史**偏哮喘——但二者可并存，需结合病史与床边超声。
- **贫血性呼吸困难**：贫血重者活动后气促，但**血氧分压多正常**——纠正贫血即可，勿把"气促"全归心肺。
- **神经精神性**要在**排除器质性**后考虑，且需警惕**癔症性过度通气**造成的呼吸性碱中毒抽搐。

**实际例子**：65 岁男性突发**胸痛、呼吸困难、咯血**，1 周前因骨折卧床 → 增强 CT 肺动脉造影见**充盈缺损** → **肺栓塞**；合并左心衰老人夜间突发**端坐呼吸、咳粉红色泡沫痰、双肺底湿啰音** → **急性左心衰肺水肿**。

## 伴随症状与问诊要点

**原理**：伴随症状帮助定位呼吸困难的系统来源；问诊要点是**起病缓急、诱发因素、呼吸类型（吸/呼/混）、体位、是否夜间加重、伴随症状（胸痛咯血发热）、既往史（心肺肾、过敏）、吸烟与职业、用药史**。

**影响因素**：病种与部位、诱因（劳力、平卧、感染、过敏、情绪）、伴随症状、年龄与基础病、用药与毒物接触。

**反向思考**：
- 呼吸困难伴**胸痛** → 心梗、肺栓塞、气胸、胸膜炎；伴**咯血** → 肺结核、支扩、心衰、肺栓塞、肺癌；伴**哮鸣音** → 哮喘、心衰；伴**发热** → 肺部感染。
- **夜间阵发性呼吸困难 + 端坐呼吸** → **左心衰**；**晨起咳嗽并端坐** → 心衰/哮喘；**平卧加重、坐起减轻**对心衰与 GERD 均有提示。
- 问诊务必问**是否接触化学毒物（CO、氰化物）、是否大量服用亚硝酸盐类（腌制食品）**——中毒性呼吸困难与变异性发绀需毒物学筛查。
- **双肺与单侧体征**：**单侧呼吸音减低、叩鼓/浊、气管偏移** → 气胸/胸腔积液/肺不张；**双肺满布湿啰音** → 肺水肿——听诊和叩诊能快速指向病因。
- 对**年轻女性反复呼吸困难、查体血气呈呼吸性碱中毒**，先排除器质性，再考虑过度通气综合征。

**实际例子**：哮喘患者夜间**呼气性哮鸣音、端坐呼吸**但痰清无泡沫 → 支氨茶碱与糖皮质激素；老人**夜间突发咳嗽粉红色泡沫痰、双肺底湿啰音、颈静脉怒张** → 急性左心衰，用利尿扩血管——二者虽都"夜间加重"，治疗全然不同。

## 反向思考·自测题（本章核心）

1. 为什么严重贫血者缺氧可不发绀？（→ 发绀取决于还原血红蛋白绝对量，贫血者还原血红蛋白总量不足）
2. 一氧化碳中毒为何严重缺氧却无发绀？（→ 形成碳氧血红蛋白呈樱红色，不增加还原血红蛋白；皮肤樱桃红）
3. 吸氧无效的发绀提示什么？（→ 异常血红蛋白（高铁/硫化血红蛋白血症）或右向左分流；需测异常血红蛋白）
4. 中心性与周围性发绀如何快速鉴别？（→ 看口唇舌黏膜是否发绀+是否伴呼吸困难+局部温度；中心性黏膜亦青紫伴杵状指，周围性以肢端为主、皮肤凉）
5. 吸气性呼吸困难的三凹征与呼气性呼吸困难的临床特点？（→ 三凹征为吸气性上气道阻塞；呼气延长伴哮鸣音为呼气性小气道病变）
6. 心源性哮喘与支气管哮喘如何鉴别？（→ 端坐呼吸、粉红色泡沫痰、双肺底湿啰音偏心衰；呼气性哮鸣音、哮喘史偏哮喘）
7. Kussmaul（深大）呼吸提示什么？与肺性呼吸困难如何区分？（→ 代谢性酸中毒代偿；血 pH 低、无气道体征）
8. 急性呼吸困难应优先排除哪些致命性疾病？（→ 急性心衰肺水肿、肺栓塞、气胸、异物、哮喘持续状态、严重过敏）

> 记忆口诀：**发绀看还原血红白，绝对量足才青紫；中心青紫黏膜+杵状指，周围肢端皮肤凉；吸氧无效想高铁、硫化，樱红提示一氧化碳；吸气三凹喉梗阻，呼气哮鸣是小气道，端坐泡沫是心衰，深大酸中毒，节律乱想脑中枢。**
