## 恶心与呕吐的定义与发生机制

**原理**：**恶心**是一种**上腹部不适感、伴欲呕吐的感觉**，多伴自主神经症状（唾液分泌、出汗、心动过速）；**呕吐**是**胃内容物从口排出的反射过程**，由**延髓呕吐中枢**（第四脑室底部）与**化学感受器触发区（CTZ）**共同调控启动。呕吐反射过程：**恶心 → 幽门括约肌收缩、下食管括约肌开放 + 腹肌与膈肌收缩 → 腹腔压力升高 → 胃内容物经口排出**。前驱有**唾液增多、出汗、苍白、心动过速、上腹不适**。

**影响因素**：刺激来源（**中枢性**[颅内压增高、脑炎、药物—化学感受器触发区、代谢紊乱]与**周围性**[消化系统：胃、肠、肝、胆、胰、腹膜炎、肠梗阻、胆囊炎]）；**反射性**（咽、心脏[心梗]、泌尿、生殖系统、前庭/耳源性、眼科）；**前庭性**（眩晕、晕动病）；**精神心理性**（厌食、紧张、神经性呕吐）；以及**呕吐物性状**（是否含胆汁、血液、粪臭、未消化食物）、时间（清晨/餐后/与进食关系）、节律（间歇/复发）、伴随腹痛/腹胀/发热等。

**反向思考**：
- **呕吐的性质、时间、内容物**提供定位线索：**清晨呕吐**见于**妊娠、尿毒症、酒精性**；**餐后呕吐**提示**胃源性（幽门梗阻[餐后 6 小时吐大量宿食]、胃道炎症）或精神性**；**喷射性呕吐**（无恶心先兆、突然喷出）**高度提示中枢性颅内压增高（脑肿瘤、脑膜炎）**——喷射性呕吐是颅内病变的警示。
- **呕吐物性状**：**含胆汁**（黄绿色，提示十二指肠远端/空肠上段，肠梗阻或胆道反流）；**含血液**（鲜红或暗红——上消化道出血）；**含大量宿食、有酸臭味**（幽门梗阻、胃潴留）；**粪臭样**（低位肠梗阻、粪瘘）——**"吐胆汁"≠"病情轻"，"吐宿食"提示幽门梗阻，"粪臭"提示低位肠梗阻**。
- **呕吐 ≠ 反流**：**呕吐**是胃内容物经口**主动排出**；**反流**（反酸/反食）是胃内容物**被动、无恶心**地反至食管或口腔——二者机制、意义不同。
- **恶心/呕吐 + 腹痛**两种急腹症要警惕：**肠梗阻（呕吐+腹痛腹胀、停止排气排便可较早出现）、急性胰腺炎、胆道疾病、急性心肌梗死（下壁心梗可仅以恶心呕吐、上腹痛为首发）**——**中年以上"恶心呕吐+上腹痛"不能只按胃病处理，要查心电图排除心梗**。
- **呕吐可以掩盖水电解质紊乱**（大量呕吐致失水、低钾、低氯性碱中毒），**长期呕吐需评估有无代谢性碱中毒与营养障碍**。

**实际例子**：40 岁男性突发**上腹部剧痛、恶心呕吐、大汗**，心电图示下壁 ST 段抬高 → **急性下壁心肌梗死**（表现为"胃痛"）；儿童**喷射性呕吐、头痛、发热、颈抵抗** → **脑膜炎/颅内压增高**。

## 恶心的病因与分类

**原理**：按其刺激途径分为：① **消化系统**（胃炎、消化性溃疡、幽门梗阻、肠梗阻、胆道疾病、胰腺炎、阑尾炎、肝炎）；② **中枢神经系统**（颅内压增高、脑炎、脑膜炎、脑肿瘤、偏头痛）；③ **前庭障碍**（梅尼埃病、晕动病）；④ **全身代谢与中毒**（尿毒症、糖尿病酮症、肝功能衰竭、药物、化学毒物、酒精）；⑤ **精神心理**（应激、焦虑、神经性呕吐）；⑥ **其他**（妊娠、心梗、肺炎、胆囊炎、阿片类镇痛药）。

**影响因素**：刺激部位、诱因（进食、体位、药物、情绪、感染）、伴随症状、病程、患者年龄与基础病、有无呕吐中枢受刺激的神经系统体征。

**反向思考**：
- **育龄女性晨起恶心呕吐**首先考虑**妊娠**（查血/尿 hCG）——不要漏诊早孕；但**妊娠剧吐**也需排除其他病因。
- **恶心呕吐 + 腹胀腹痛 + 停止排气排便** → **肠梗阻**（机械性/麻痹性），需拍立位腹平片或 CT——不能只当"肠胃炎、肚子胀"。
- **呕吐伴剧烈头痛、视乳头水肿、意识障碍** → **颅内压增高/脑肿瘤**（喷射性呕吐+头痛+视乳头水肿为颅高压三联征），应紧急影像学检查而非简单止吐。
- **恶心呕吐 + 黄疸、右上腹痛** → **胆道/肝炎/胆囊炎**；**呕吐咖啡色物+黑便** → **上消化道出血**——伴随症状决定定位。
- **神经性呕吐**（精神心理性）：**青年女性、与情绪相关、进食后立即呕吐、体重不下降**——但需先排除器质性与代谢性（早孕、甲亢、胃潴留）。

**实际例子**：中年女性突发**右上腹绞痛、恶心呕吐、发热、黄疸（Charcot 三联征）** → 急性化脓性胆管炎；老年男性**餐后上腹饱胀、大量呕吐宿食** → **幽门梗阻**（需查幽门部肿瘤或溃疡）。

## 烧心与反流的定义与发生机制

**原理**：**烧心**（胃灼热）指**胸骨后或剑突下的烧灼样不适感**，多由**胃食管反流（GERD）**引起；**反流**指**胃内容物（甚至胆汁、食物、酸）逆流至食管、口腔**。关键机制是**下食管括约肌（LES）功能不全**（压力降低、一过性松弛增加），加上**食管清除能力下降、胃排空延迟、食管黏膜屏障受损**，致酸/碱反流刺激食管黏膜，产生烧心、反酸、胸骨后痛、吞咽不适。

**影响因素**：LES 压力与一过性松弛频率、食管廓清能力、胃酸与反流物性质（酸、胆汁）、食管黏膜屏障、肥胖、妊娠、腹压增高（腹胀、便秘）、饮食（高脂、咖啡、酒精、辛辣、大量进食）、药物（钙拮抗剂、茶碱、抗胆碱能药）、体位（平卧、弯腰）、食管裂孔疝、幽门梗阻/胃潴留、精神压力。

**反向思考**：
- **烧心 ≠ 一定 GERD**：烧心可见于**胃炎、消化性溃疡、食管炎、食管癌、食管运动障碍、冠心病（心源性）、功能性消化不良、癌性**——**胸骨后烧灼样痛需与心绞痛/心梗鉴别**，尤其中年以上伴心悸、胸闷者要先做心电图。
- **"烧心"的夜间加重、与进食/卧位关系**：平卧、弯腰、餐后烧心加重，坐起或口服抗酸药减轻——提示 **GERD**；若抗酸无效、伴吞咽困难、消瘦，要警惕**食管癌**。
- **反流性食管炎 vs 真正器质性疾病**：咽下烧心、反酸、胸骨后痛需与**心源性胸痛、食管癌、食管贲门失弛缓症、食管结核、食管异物**鉴别。长期**反酸+吞咽困难+体重下降**是食管癌警示。
- **反流误吸入**可致**慢性咳嗽、哮喘样发作、声音嘶哑、反复肺炎**——"肺外表现"易被忽略，GERD 是慢性咳嗽/难治性哮喘的病因之一。

**实际例子**：一位**体重偏高中年男性，餐后平卧时胸骨后烧灼感、反酸、夜间咳嗽** → **胃食管反流病（GERD）**；若出现**进行性吞咽困难、消瘦、40 岁以上** → 需**胃镜排除食管癌**。

## 烧心/反流的病因与伴随症状/问诊要点

**原理**：烧心反流病因以**GERD**为主，还包括**食管运动障碍、食管裂孔疝、孕期激素致 LES 松弛、肥胖腹压增高、胃排空延迟（胃轻瘫）**；伴随症状（反酸、胸痛、咳嗽、吞咽困难、声嘶、烧灼、上腹不适）；问诊要点是**诱因（饮食、体位、用药）、是否夜间/餐后加重、与体位关系、是否伴吞咽困难/消瘦/胸痛/咳嗽、既往史、是否服钙拮抗剂/茶碱等**。

**影响因素**：病种、诱因（高脂/暴食、饮酒、咖啡、吸烟、平卧、腹压增高）、伴随症状（吞咽困难、消瘦、胸痛、慢性咳嗽、声嘶）、年龄、用药史、BMI 与妊娠、精神因素。

**反向思考**：
- **烧心+吞咽困难+消瘦（进行性加重）** → **食管癌**排首位（报警症状）；**烧心+吞咽困难（间歇、与情绪/进食有关）+ 无消瘦** → 可能与**贲门失弛缓症、食管痉挛**有关。
- **烧心+胸痛**一定要排除**心源性**——先把心脏查明白，再谈 GERD，尤其既往有冠心病危险因子（高血压、糖尿病、吸烟、肥胖）者。
- **慢性咳嗽、声音嘶哑、咳痰、（难治性）哮喘**当除外肺内病因后要问**反酸、烧心史**——胃食管反流是"被低估的咳嗽病因"。
- 问诊需问**是否长期服用甘草、NSAIDs、双膦酸盐、四环素、钾片、阿司匹林**——药物性食管炎/溃疡可致吞咽痛。

**实际例子**：中年女性**慢性咽部异物感、咳不出咽不下、夜间烧心**，耳鼻喉科与呼吸科检查无明显器质病变，追问有**反酸、平卧加重** → 胃镜示**反流性食管炎** → **GERD 的"咽喉"表现**。

## 吞咽困难的定义、分类与鉴别

**原理**：**吞咽困难**指吞咽时**食物（或液体）在口咽或食管通过受阻、困难、有梗阻感**。分为：① **机械性（梗阻性）**（食管癌、贲门失弛缓、食管狭窄、食管良性肿瘤、食管裂孔疝、纵隔肿瘤、主动脉瘤压迫）；② **动力性（神经肌肉性）**（食管运动障碍、贲门失弛缓、弥漫性食管痉挛、硬皮病、食管肌层异常）；③ **口咽性（神经性）**（延髓麻痹、假性延髓麻痹、重症肌无力、多发性硬化、吞咽反射启动障碍——伴呛咳、鼻腔反流、误吸）。

**影响因素**：病变部位（口咽性 vs 食管性）、病因性质（机械性 vs 动力性）、进展速度（进行性[食管癌]、间歇性[贲门失弛缓、食管痉挛]）、食物性状（固体/液体——**机械性早期固体困难、动力性液体与固体均困难**）、年龄与性别、有无反酸/消瘦/疼痛/呛咳、神经肌肉体征。

**反向思考**：
- **"进行性吞咽困难、先固体后流质、伴消瘦、40 岁以上"** → **食管癌**（典型报警信号）；**"间歇性、时好时坏、与情绪有关、年轻人、对冷热刺激敏感"** → **贲门失弛缓症或弥漫性食管痉挛**。
- **机械性 vs 动力性**的关键区分：**机械性**早期**固体难、液体可过**（进行性）；**动力性**（失弛缓）**液体与固体均难**，且**胀气、胸骨后痛、进食后反流**。
- **口咽性吞咽困难**：**吞咽启动即困难、伴呛咳、食物从鼻腔反流、声音嘶哑**——提示**神经肌肉疾病（延髓性）**，与食管性不同（食管性为"食物卡在胸骨后"）。
- **吞咽困难伴烧心、反酸** → **食管癌(在中上段)、狭窄、GERD 相关食管狭窄、食管裂孔疝**；**伴呕血/黑便、贫血、消瘦** → **食管/贲门肿瘤**。
- **精神性（癔球症）**：**咽部异物感、吞咽无明显困难、无消瘦、与情绪相关**——但需排除器质性疾病后考虑。

**实际例子**：50 岁男性**进行性吞咽困难（先难咽干硬食物，后流质），体重下降半年、吸烟饮酒史** → **食管癌**（需胃镜+活检）；青年男性**冷暖饮诱发、胸骨后不适、液体也难咽、间歇发作** → **贲门失弛缓症/弥漫性食管痉挛**（食管测压确诊）。

### 机械性 vs 动力性吞咽困难对比表

| 对比项 | 机械性（梗阻性） | 动力性（神经肌肉性） |
|---|---|---|
| 病因 | 食管癌、狭窄、贲门失弛缓、纵隔肿瘤 | 食管运动障碍、失弛缓、硬皮病、神经性 |
| 进展 | 进行性加重 | 间歇性、波动 |
| 食物性质 | 早先固体难、液体可过 | 液体与固体均难 |
| 反流 | 可反流，早期少 | 进食后反流、胀气明显 |
| 疼痛 | 可伴胸骨后痛 | 可为胸骨后痛（痉挛） |
| 典型病种 | 食管癌、良性狭窄 | 贲门失弛缓、弥漫性食管痉挛、神经性（呛咳） |

## 反向思考·自测题（本章核心）

1. 喷射性呕吐、无恶心先兆提示什么？（→ 中枢性颅内压增高（脑肿瘤、脑膜炎））
2. 呕吐物含宿食酸臭、粪臭样分别提示什么？呕胆汁说明什么？（→ 宿食：幽门梗阻/胃潴留；粪臭：低位肠梗阻；胆汁：十二指肠远端梗阻/胆汁反流）
3. 中年以上"恶心呕吐+上腹痛"为何要查心电图？（→ 急性下壁心肌梗死可表现为上腹痛恶心）
4. 烧心一定都是胃食管反流吗？为何必须与心绞痛/心梗鉴别？（→ 可对应胃食管反流、胃炎、溃疡、食管癌、心源性；胸骨后烧灼痛与心源性不易区分，先查心电）
5. 进行性吞咽困难、先固体后流质、伴消瘦提示什么？（→ 食管癌，需胃镜；报警症状）
6. 机械性与动力性吞咽困难如何区分？（→ 机械性早固体难、液体可过、进行性；动力性液体固体均难、间歇、伴反流胀气）
7. 口咽性（神经性）吞咽困难的临床特点？（→ 吞咽启动难、呛咳、食物鼻腔反流、声嘶，提示神经肌肉病）
8. 慢性咳嗽/声嘶为何要想到胃食管反流？（→ GERD 的肺外表现，易被忽略）
9. 长期大量呕吐会带来什么水电解质紊乱？（→ 失水、低钾、低氯性碱中毒；长期呕吐需评估代谢性碱中毒与营养障碍）

> 记忆口诀：**恶心呕吐中枢周围分，喷射无恶心想颅内，晨吐想妊娠尿毒酒精，吐宿食幽门堵，粪臭低位梗，三高（心脑肠胃腹痛）先排心梗；烧心反流看 LES，平卧餐后重、坐起酸药轻，烧心+胸痛先查心；吞咽困难机械进、动力波动液体固均难，进行性消瘦盯食管癌，呛咳鼻反流想神经性。**
